## 概述
本目录包含 TTPOS WebSocket 系统各个服务模块的功能说明文档。

## 服务列表

### 1. [WebSocket 服务](./websocket.md) - 实时通信核心
- WebSocket 连接升级和管理
- 实时消息推送（单播/广播）
- gRPC 远程调用接口
- 消息持久化和重试机制

### 2. [Connection 服务](./connection.md) - 连接管理
- WebSocket 连接生命周期管理
- 连接认证和权限验证
- 心跳检测和状态维护
- 连接池管理和资源清理

### 3. [Message 服务](./message.md) - 消息处理
- 消息接收、解析和验证
- 消息路由和转发
- 消息存储和状态管理
- 失败重试和错误处理

## 服务架构

### 服务注册模式
所有服务都采用接口定义 + 实现注册的模式：
```go
// 定义接口
type IWebsocketService interface {
    SendMessage(ctx context.Context, req *SendMessageReq) (*SendMessageResp, error)
}

// 注册实现
service.RegisterWebsocket(websocketImpl)

// 获取服务实例
svc := service.Websocket()
```

### 上下文传递
所有服务方法都需要传入 `context.Context` 对象，用于：
- 请求链路追踪
- 超时控制
- 取消信号传递
- 元数据传递

## 数据流转

### WebSocket 连接流程
```
HTTP 请求 → WebSocket 升级 → 连接认证 → 加入连接池 → 心跳维护
```

### 消息推送流程
```
接收推送请求 → 目标连接查找 → 消息发送 → 状态记录 → 结果返回
```

### 广播消息流程
```
接收广播请求 → 遍历连接池 → 批量发送 → 统计结果 → 状态更新
```

### 离线消息处理
```
检测连接断开 → 标记离线消息 → 存储待发送 → 重连时重发
```

### 消息处理

- 消息持久化存储

### 性能优化
- 连接池复用

## 注意事项

1. **连接管理**: WebSocket 连接需要妥善管理，避免连接泄漏
2. **消息可靠性**: 重要消息需要确认机制，确保送达
3. **性能监控**: 监控连接数、消息量、错误率等指标
4. **安全控制**: 连接认证、消息权限验证
5. **资源限制**: 控制连接数、消息大小、发送频率
