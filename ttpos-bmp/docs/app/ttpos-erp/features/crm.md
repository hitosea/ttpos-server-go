# CRM 服务功能说明

## 概述
CRM 服务提供客户关系管理功能，包括地址管理和联系人管理。

## 服务接口

### ICrm - 客户关系管理

#### 地址管理
- **GetAddressList**: 获取地址列表
  - 根据查询条件过滤并返回地址信息列表
  
- **GetAddress**: 获取地址详情
  - 根据地址名称获取详细信息
  
- **CreateAddress**: 创建地址
  - 创建新的地址记录
  
- **UpdateAddress**: 更新地址
  - 更新现有地址的信息
  
- **DeleteAddress**: 删除地址
  - 删除指定的地址记录

#### 联系人管理
- **GetContactList**: 获取联系人列表
  - 根据查询条件过滤并返回联系人信息列表
  
- **GetContact**: 获取联系人详情
  - 根据联系人名称获取详细信息
  
- **CreateContact**: 创建联系人
  - 创建新的联系人记录
  
- **UpdateContact**: 更新联系人
  - 更新现有联系人的信息
  
- **DeleteContact**: 删除联系人
  - 删除指定的联系人记录

## 业务场景

### 地址管理
- 客户收货地址管理
- 供应商地址管理
- 公司/分支机构地址管理
- 支持多地址场景

### 联系人管理
- 客户联系人信息维护
- 供应商联系人信息维护
- 支持多联系人场景
- 联系人与地址可以关联

## 使用说明

### 服务注册
```go
service.RegisterCrm(crmImpl)
```

### 服务调用
```go
// 获取 CRM 服务实例
crm := service.Crm()

// 创建地址
address, err := crm.CreateAddress(ctx, &crm.CreateAddressReq{
    // 地址信息
})

// 创建联系人
contact, err := crm.CreateContact(ctx, &crm.CreateContactReq{
    // 联系人信息
})
```

## 数据关系

### 地址与实体关联
- 地址可以关联到客户、供应商、公司等实体
- 支持一对多关系（一个实体可以有多个地址）

### 联系人与实体关联
- 联系人可以关联到客户、供应商等实体
- 联系人可以关联到具体地址
- 支持一对多关系

## 注意事项
1. 地址和联系人都使用名称作为唯一标识
2. 删除地址或联系人前需要检查关联关系
3. 更新操作需要提供完整的实体信息
4. 查询列表支持多种过滤条件
