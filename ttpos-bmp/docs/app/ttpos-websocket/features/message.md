### 模块：Message（消息处理）

定位：负责 WebSocket 消息的处理、路由、存储和状态管理，确保消息的可靠传输和追踪。

主要功能
- ProcessMessage：处理接收到的 WebSocket 消息
- RouteMessage：根据消息类型和目标路由消息
- StoreMessage：持久化消息记录到数据库
- RetryFailedMessage：重试发送失败的消息

核心数据结构
- MessagePayload：消息载荷（类型、内容、目标、时间戳）
- MessageRoute：消息路由信息（来源、目标、路径）
- MessageStatus：消息状态（待发送、发送中、成功、失败）
- RetryPolicy：重试策略（次数、间隔、退避算法）

关键流程
1) 消息接收：WebSocket 接收 → 消息解析 → 格式验证 → 类型识别
2) 消息路由：目标解析 → 连接查找 → 权限验证 → 消息转发
3) 消息存储：消息记录 → 状态更新 → 日志记录 → 统计更新
4) 失败重试：失败检测 → 重试策略 → 延迟发送 → 状态更新

消息类型
- 心跳消息：维持连接活跃状态
- 业务消息：订单、商品、会员等业务数据
- 系统消息：配置更新、状态同步等
- 广播消息：面向所有连接的通知

错误处理
- 格式错误：JSON 解析失败、字段缺失
- 路由错误：目标不存在、权限不足
- 发送错误：网络异常、连接断开
- 存储错误：数据库异常、磁盘空间不足

性能优化
- 消息队列：异步处理消息，避免阻塞
- 批量操作：批量存储和更新，提高效率
- 缓存机制：缓存热点数据，减少数据库访问
- 压缩传输：大消息压缩，节省带宽
