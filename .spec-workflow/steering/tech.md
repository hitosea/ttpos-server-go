# TTPOS 收银系统技术栈

## 项目类型

TTPOS是一套基于微服务架构的分布式餐饮收银系统，包含Web API服务、实时通信服务、业务中台服务等多个组件，支持高并发、高可用的生产环境部署。

## 核心技术栈

### 主要编程语言
- **Go 1.23+**：主要后端服务开发语言
- **PHP 8.0+**：管理后台开发语言（ThinkPHP框架）
- **JavaScript/TypeScript**：前端界面开发

### 关键依赖库和框架

#### Go后端框架
- **Gin v1.9+**：高性能HTTP Web框架
- **GORM v1.25+**：Go语言ORM框架，支持多种数据库
- **Viper v1.15+**：Go配置管理库
- **Logrus v1.9+**：结构化日志库
- **JWT-Go v4.5+**：JWT认证库

#### 微服务组件
- **gRPC v1.56+**：高性能RPC框架（外送服务）
- **Protocol Buffers**：接口定义和数据序列化
- **Nacos**：服务注册与发现
- **RocketMQ**：分布式消息队列

#### 前端技术栈
- **Vue 3**：渐进式JavaScript框架
- **Element Plus**：Vue 3 UI组件库
- **TypeScript**：类型安全的JavaScript超集
- **Vite**：下一代前端构建工具

### 应用架构

采用微服务架构设计，主要包含以下服务模块：

#### 核心服务层
- **main/**：主要业务服务（收银、桌台、订单、会员等）
- **websocket/**：实时通信服务
- **ttpos-bmp/**：业务中台服务
- **redis-proxy/**：Redis代理服务
- **admin/**：管理后台服务

#### 架构模式
- **分层架构**：Controller -> Service -> Repository
- **依赖注入**：接口驱动的松耦合设计
- **事件驱动**：基于事件总线的异步处理
- **CQRS模式**：命令查询职责分离

## 技术决策与理由

### 核心技术选型
1. **Go语言**：高性能、并发能力强、部署简单，适合高并发服务
2. **微服务架构**：服务解耦、独立部署、易于扩展和维护
3. **MySQL + Redis**：成熟稳定的数据存储方案，支持高并发访问
4. **Docker容器化**：环境一致性、快速部署、易于扩缩容

### 架构设计决策
1. **分层架构**：清晰的代码组织，提高可维护性
2. **接口驱动**：依赖倒置，降低耦合度
3. **事件驱动**：异步处理，提高系统响应性
4. **CQRS模式**：读写分离，优化性能

### 开发工具选择
1. **Git Flow**：标准化的分支管理流程
2. **Docker Compose**：本地开发环境一致性
3. **Makefile**：跨平台构建脚本
4. **Swagger**：标准化的API文档
