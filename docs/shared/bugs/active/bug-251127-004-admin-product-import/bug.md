## 问题描述

### 现象

新管理端桌面版商品批量导入功能中，计价方式字段存在以下3个问题：

1. **输入验证缺失** - 计价方式输入值不在约定范围内时，导入后预览页面计价方式显示为未选择
2. **必填约束缺失** - 文档标注计价方式标识为必填，但实际未约束必填（无提示，可直接导入）
3. **默认值错误** - 计价方式未选择时，系统默认为"小数计价"，期望应为"整数计价"

### 复现步骤

**问题1 - 输入验证缺失：**
1. 准备商品导入 Excel 文件
2. 在计价方式列输入不在约定值范围内的值（如：invalid_value）
3. 点击导入并预览
4. 观察：预览页面显示计价方式为"未选择"

**问题2 - 必填约束缺失：**
1. 准备商品导入 Excel 文件
2. 计价方式列留空（不填写任何值）
3. 点击导入
4. 观察：系统未提示该字段必填，允许导入

**问题3 - 默认值错误：**
1. 准备商品导入 Excel 文件
2. 计价方式列留空
3. 导入成功后查看商品详情
4. 观察：计价方式显示为"小数计价"

### 预期行为

1. **输入验证**：当计价方式值不在约定范围时，应在导入时显示错误提示，阻止导入
2. **必填约束**：计价方式为必填字段，留空时应显示明确提示，阻止导入
3. **默认值**：当计价方式未填写时，默认值应为"整数计价"而非"小数计价"

### 实际行为

1. 输入非法值可以导入，但预览时显示未选择
2. 必填字段留空可以导入，无任何提示
3. 默认值为"小数计价"，与期望不符

## 初步分析

### 根本原因（待确认）

1. **前端验证缺失**：
   - 导入模块未对计价方式进行枚举值校验
   - 未实现必填字段的前端验证

2. **后端验证缺失**：
   - API 接口未对计价方式字段进行严格校验
   - 未实现必填字段的后端验证

3. **默认值配置错误**：
   - 商品 Model 或数据库层面的默认值配置为"小数计价"
   - 应修改为"整数计价"
