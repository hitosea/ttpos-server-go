1. **引入标准化机制**：使用 PaymentID 代替 Name 作为唯一标识
2. **统一处理逻辑**：提取公共方法，减少代码重复
3. **保持向后兼容**：兼容旧数据，平滑过渡

### 关键技术

- 数据库字段扩展
- ERP 接口适配
- 前后端联调
- 支付方式查询优化

### 注意事项

- 确保数据一致性
