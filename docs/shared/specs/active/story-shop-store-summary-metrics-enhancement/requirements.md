## 📝 用户故事

**作为** 店长/运营人员/财务人员
**我想** 在门店汇总统计的营业数据、退款金额、支付方式表格中查看各列的平均值，并在退款汇总中查看平均退款额
**以便于** 提升数据分析能力，支持运营决策，获得更完整的报表导出

---

## 功能需求

### Requirement 1: 表格平均值行

**用户故事**: 作为店长/运营人员，我想在汇总表格底部看到各列的平均值，以便于快速对比各门店/时段的平均表现

#### 验收标准

1. **WHEN** 用户查看营业数据汇总表格 **THEN** 表格底部 **SHALL** 固定显示"平均值"行，展示各数值列的平均值（总和/个数）
2. **WHEN** 用户查看退款金额汇总表格 **THEN** 表格底部 **SHALL** 固定显示"平均值"行，展示各数值列的平均值（总和/个数）
3. **WHEN** 用户查看支付方式汇总表格 **THEN** 表格底部 **SHALL** 固定显示"平均值"行，展示各数值列的平均值（总和/个数）

---

### Requirement 2: 平均值基于筛选全量数据计算

**用户故事**: 作为运营人员，我想平均值基于筛选后的全部数据计算，以便于获得准确的整体平均值

#### 验收标准

1. **WHEN** 用户使用筛选条件筛选数据 **THEN** 平均值 **SHALL** 基于筛选后的全部数据重新计算，而非仅当页数据
2. **WHEN** 用户切换分页 **THEN** 平均值 **SHALL** 保持不变（因为基于全量数据）
3. **WHEN** 筛选结果为空 **THEN** 平均值行 **SHALL** 显示为 0 或 "-"

---

### Requirement 3: 退款表新增平均退款额字段

**用户故事**: 作为店长/财务人员，我想查看每条记录的平均退款额，以便于评估单笔退款的严重程度

#### 验收标准

1. **WHEN** 用户查看退款金额汇总表 **THEN** 表头 **SHALL** 新增"平均退款额"列
2. **WHEN** 退款金额汇总表显示数据 **THEN** 平均退款额 **SHALL** 按公式"退款金额/退款单数"计算
3. **IF** 退款单数为 0 **THEN** 平均退款额 **SHALL** 显示为 0 或 "-"

---

### Requirement 4: 导出文档平均值支持

**用户故事**: 作为财务人员，我想导出的报表包含平均值统计，以便于减少手动计算工作量

#### 验收标准

1. **WHEN** 用户导出营业数据汇总表格 **THEN** 导出的 Excel 文档 **SHALL** 在最后一行包含"平均值"记录
2. **WHEN** 用户导出退款金额汇总表格 **THEN** 导出的 Excel 文档 **SHALL** 在最后一行包含"平均值"记录，且包含"平均退款额"列
3. **WHEN** 用户导出支付方式汇总表格 **THEN** 导出的 Excel 文档 **SHALL** 在最后一行包含"平均值"记录

---

### Requirement 5: 营业数据表新增业绩分类字段

**用户故事**: 作为运营人员，我想在营业数据汇总表中按渠道分类查看到店业绩和外卖业绩，以便于分析不同渠道的业绩贡献

#### 验收标准

1. **WHEN** 用户查看营业数据汇总表（明细表/汇总表） **THEN** 表头在"现金AC"列后 **SHALL** 依次显示"到店业绩"、"到店订单数"、"外卖业绩"、"外卖订单数"四列
2. **WHEN** 营业数据汇总表显示数据 **THEN** "到店业绩" **SHALL** 等于堂食订单金额+外带订单金额
3. **WHEN** 营业数据汇总表显示数据 **THEN** "到店订单数" **SHALL** 等于堂食订单数+外带订单数
4. **WHEN** 营业数据汇总表显示数据 **THEN** "外卖业绩" **SHALL** 等于外送订单金额+第三方外卖（Grab、LINE MAN等）订单金额
5. **WHEN** 营业数据汇总表显示数据 **THEN** "外卖订单数" **SHALL** 等于外送订单数+第三方外卖订单数
6. **WHEN** 用户导出营业数据汇总表格 **THEN** 导出的 Excel 文档 **SHALL** 包含这四个新增列
7. **WHEN** 显示平均值行 **THEN** 这四个新增列 **SHALL** 同样显示对应的平均值

## 风险和缓解

### 风险 1: 大数据量下平均值计算性能

**影响**: 中
**缓解措施**: 在数据库层面完成聚合计算（SUM/COUNT），避免全量数据传输到应用层

### 风险 2: 平均值精度和小数位数

**影响**: 低
**缓解措施**: 统一规范数值精度，建议保留 2 位小数，与现有金额字段保持一致
