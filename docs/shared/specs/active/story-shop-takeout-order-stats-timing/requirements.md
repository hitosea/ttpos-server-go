## 📝 用户故事

**作为** 店长/商户管理员/运营人员
**我想** 外卖订单统计能够在未完成时实时显示，完成后按完成时间准确归类
**以便于** 既能实时监控订单处理情况，又能获得准确的时段统计数据

---

## 功能需求

### Requirement 1: 订单统计查询时间逻辑调整

**用户故事**: 作为店长，我想让订单统计根据订单状态动态选择时间字段，以便于获得准确的时段统计

#### 验收标准

1. **WHEN** 查询某时段订单统计 **AND** 订单未完成 **THEN** 系统 **SHALL** 按接单时间（accepted_time）匹配时段
2. **WHEN** 查询某时段订单统计 **AND** 订单已完成 **THEN** 系统 **SHALL** 按完成时间（completed_time）匹配时段
3. **IF** 订单 1:30 接单、2:15 完成 **THEN** 查询 1-2 点统计 **SHALL** 不包含该订单
4. **IF** 订单 1:30 接单、2:15 完成 **THEN** 查询 2-3 点统计 **SHALL** 包含该订单
5. **IF** 订单 1:30 接单、未完成 **THEN** 查询 1-2 点统计 **SHALL** 包含该订单

### Requirement 2: 查询条件构建

**用户故事**: 作为系统，需要根据订单状态动态构建查询条件

#### 验收标准

1. **WHEN** 构建查询条件 **THEN** 系统 **SHALL** 使用 UNION 或 OR 逻辑合并两种状态的查询
2. **IF** 订单状态为已完成（order_state = 40） **THEN** 系统 **SHALL** 使用 completed_time 字段
3. **IF** 订单状态非已完成 **THEN** 系统 **SHALL** 使用 accepted_time 字段
