## 用户故事

**作为** 内部微服务（如 Main 模块）
**我想** 通过 gRPC 接口查询送货单列表及其商品明细
**以便于** 实现 ERP 数据互通和接口标准化访问

---

## 功能需求

### Requirement 1: 送货单列表查询接口

**用户故事**: 作为内部微服务，我想通过 gRPC 接口查询送货单列表，以便于获取 ERP 送货单数据

#### 验收标准

1. **WHEN** 调用 GetDeliveryNoteList gRPC 接口 **THEN** 系统 **SHALL** 返回符合筛选条件的送货单分页列表
2. **WHEN** 返回送货单数据 **THEN** 系统 **SHALL** 包含对应的 DeliveryNoteItem 商品明细
3. **WHEN** 请求参数缺失或无效 **THEN** 系统 **SHALL** 返回明确的错误信息

## 约束条件

### 技术约束

- Go 版本: 1.23+
- 框架: GoFrame v2.x
- 必须遵循 BMP 模块分层架构: API -> Controller -> Logic -> DAO
- Protobuf 定义位于 `manifest/protobuf/` 目录
- 必须遵循 CLAUDE.md 和 ttpos-bmp/.cursor/rules/ 规范

## 风险和缓解

### 风险 1: 送货单数据量大时查询性能受影响

**影响**: 中
**缓解措施**: 实现合理的分页机制，限制单次查询数量

### 风险 2: 接口调用频率过高影响服务稳定性

**影响**: 低
**缓解措施**: 考虑添加接口限流策略（可在后续迭代中实现）
