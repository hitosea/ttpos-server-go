## 📋 概述

为盘点单表（`ttpos_stock_reconciliation`）的 `type` 字段增加新的盘点周期类型，以支持更精细化的库存盘点管理需求。当前 `type` 字段仅支持两种盘点类型：指定物品盘点和全部物品盘点，需要扩展为支持日盘、周盘、月盘三种周期性盘点类型。

## 🎯 产品对齐

该功能扩展支持餐饮行业的库存管理规范化需求，帮助商户建立定期盘点机制，提高库存准确性，降低损耗。

## 📝 用户故事

**作为** 库存管理员  
**我想** 创建日盘、周盘、月盘类型的盘点单  
**以便于** 按照不同的周期规范化地进行库存盘点

## 功能需求

### Requirement 1: 扩展盘点单类型枚举

**用户故事**: 作为库存管理员，我想在创建盘点单时选择日盘、周盘或月盘类型，以便于按照不同周期进行盘点。

#### 验收标准

1. **WHEN** 创建盘点单 **THEN** 系统 **SHALL** 支持选择以下盘点类型：
   - 1 - 指定物品盘点（保持不变）
   - 2 - 全部物品盘点（保持不变）
   - 3 - 日盘（新增）
   - 4 - 周盘（新增）
   - 5 - 月盘（新增）

2. **IF** 选择日盘/周盘/月盘类型 **THEN** 系统 **SHALL** 正确保存并显示该类型

3. **WHEN** 查询盘点单 **THEN** 系统 **SHALL** 正确返回盘点类型字段值及对应说明

#### 具体要求

- [x] 1.1 创建数据库迁移文件，修改 `type` 字段的注释，增加新类型说明
- [x] 1.2 同步更新 `admin/database/seeds/shop_01.sql` 中的表结构定义
- [x] 1.3 同步更新 Go Model 文件的注释说明
- [x] 1.4 更新 DTO 请求参数验证，添加 `binding:"oneof=1 2 3 4 5"` 验证规则
