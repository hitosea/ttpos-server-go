## 🎯 核心功能

允许商品选择时，套餐分组、属性、加料可以在一定范围内自由选择，而不是必选或固定数量。

### 关键字段

- **套餐分组**：`optional_min_count`（最小数量）、`optional_count`（最大数量）
- **属性组**：`min_selection`（最小数量）、`max_selection`（最大数量）
- **加料**：`sauce_min_selection`（最小数量）、`sauce_max_selection`（最大数量）
