## 📝 用户故事

**作为** 店长/商户管理员
**我想** 在门店汇总统计中看到符合行业习惯的字段名称（TC/AC）、完整的现金统计数据、以及带编号的店铺名称
**以便于** 更快理解营业数据、进行财务对账、快速定位多店铺数据

---

## 功能需求

### Requirement 1: 表头字段名称修改

**用户故事**: 作为店长,我想看到符合行业习惯的字段名称,以便于更快理解数据含义

#### 字段名称对照表

| 原字段名         | 新字段名   |
| ---------------- | ---------- |
| 门店名称         | 店铺名称   |
| 订单金额         | 总营业额   |
| 实付金额         | 实收金额   |
| 订单数量（单）   | TC         |
| 订单金额单均     | AC         |

#### 验收标准

1. **WHEN** 查看门店汇总统计明细表 **THEN** 系统 **SHALL** 按新的字段名称展示表头
2. **WHEN** 查看门店汇总统计汇总表 **THEN** 系统 **SHALL** 按新的字段名称展示表头

---

### Requirement 2: 新增现金统计字段

**用户故事**: 作为财务人员,我想看到现金收款的统计数据,以便于进行现金对账

#### 新增字段定义

| 字段名   | 计算逻辑                                  | 说明             |
| -------- | ----------------------------------------- | ---------------- |
| 现金TC   | COUNT(payment_method='Cash')              | 现金支付订单数   |
| 现金金额 | SUM(amount WHERE payment_method='Cash')   | 现金支付总金额   |
| 现金AC   | 现金金额 / 现金TC                         | 保留2位小数      |

#### 验收标准

1. **WHEN** 表格中存在现金支付订单 **THEN** 系统 **SHALL** 正确计算并展示现金TC（现金支付订单数）
2. **WHEN** 表格中存在现金支付订单 **THEN** 系统 **SHALL** 正确计算并展示现金金额（现金支付总金额）
3. **WHEN** 表格中存在现金支付订单 **THEN** 系统 **SHALL** 正确计算并展示现金AC（现金金额/现金TC，保留2位小数）
4. **WHEN** 表格中无现金支付订单 **THEN** 系统 **SHALL** 现金TC显示0，现金金额显示0，现金AC显示0.00

---

### Requirement 3: 表头字段排序调整

**用户故事**: 作为运营人员,我想按重要性顺序查看数据,以便于快速获取关键指标

#### 字段顺序

按以下顺序展示：
> 营业日 | 店铺名称 | 总营业额 | 实收金额 | TC | AC | 现金TC | 现金金额 | 现金AC | 用餐人数（人） | 消费桌数（桌） | 平均客单价 | 订单金额人均 | 订单金额单均 | 实付金额单均 | 点餐订单金额 | 桌台订单金额 | 外送订单金额

#### 验收标准

1. **WHEN** 查看门店汇总统计明细表/汇总表 **THEN** 系统 **SHALL** 按上述顺序展示字段

---

### Requirement 4: 店铺名称格式优化

**用户故事**: 作为店长,我想通过店铺编号快速定位店铺,以便于管理多店铺数据

#### 格式规范

- 格式：`{店铺编号} {商家名称}`
- 示例：`001 华莱士xxx门店`

#### 排序规则

1. 未设置店铺编号的排在最前
2. 优先数字（0-9）
3. 然后字母（a-z）

#### 验收标准

1. **WHEN** 店铺设置了编号 **THEN** 系统 **SHALL** 以"编号 名称"格式显示店铺名称
2. **WHEN** 店铺未设置编号 **THEN** 系统 **SHALL** 仅显示店铺名称
3. **WHEN** 多店铺排序 **THEN** 系统 **SHALL** 按规则排序（无编号优先，数字优先于字母）

---

### Requirement 5: 导出功能同步调整

**用户故事**: 作为财务人员,我想导出的数据与页面一致,以便于进行财务审计

#### 验收标准

1. **WHEN** 导出 Excel **THEN** 系统 **SHALL** 导出与页面一致的字段名称
2. **WHEN** 导出 Excel **THEN** 系统 **SHALL** 导出与页面一致的字段顺序
3. **WHEN** 导出 Excel **THEN** 系统 **SHALL** 包含新增的现金统计字段（现金TC、现金金额、现金AC）
