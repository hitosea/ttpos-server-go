# Excel 格式定义文档

> 本文档定义订单数据导入的 Excel 文件格式规范。
> 
> **💡 MVP 方案**：最小可执行版本，仅包含核心字段

---

## 📋 文件要求

- **文件格式**: `.xlsx`（Excel 2007+）
- **文件大小**: 最大 10MB
- **工作表数量**: 2 个（订单基本信息、订单明细）
- **单次导入限制**: 最多 5000 条订单

### 📄 示例文件

已提供 Excel 示例文件：`订单数据导入示例.xlsx`

**生成示例文件**：
```bash
# 需要安装 openpyxl 库
pip3 install openpyxl

# 运行生成脚本
python3 create_excel.py
```

生成的示例文件包含：
- Sheet1: 订单基本信息（3 条示例数据）
- Sheet2: 订单明细（6 条示例数据）

### 订单明细 → 数据库表映射

**说明**：订单明细会创建两条记录：
1. `ttpos_sale_order`（销售订单表）- 每个订单号创建一条记录

| 备注 | `ttpos_sale_order_product` | `remark` | 直接映射，VARCHAR(255)（可选） |

## ✅ 数据校验规则

### 订单基本信息校验

1. **订单号**：
   - 必填，不能为空
   - 不能重复（如果已存在则跳过）
   - 长度不超过 255 个字符

2. **下单时间**：
   - 必填，不能为空
   - 格式：`YYYY-MM-DD HH:mm:ss`
   - 示例：`2025-11-19 14:30:00`

3. **订单状态**：
   - 必填，不能为空
   - 取值范围：`0`（待付款）、`1`（已完成）、`2`（已取消）

4. **订单类型**：
   - 必填，不能为空
   - 取值范围：`0`（桌台订单）、`1`（点餐订单）、`2`（会员端订单）

5. **用餐方式**：
   - 必填，不能为空
   - 取值范围：`0`（堂食）、`1`（打包）

6. **订单金额**：
   - 必填，不能为空
   - 必须为数字，保留2位小数
   - 必须大于等于 0

7. **订单原价**：
   - 必填，不能为空
   - 必须为数字，保留2位小数
   - 必须大于等于 0
   - 必须大于等于订单金额（折后价）

8. **门店名称**：
   - 必填，不能为空
   - 门店必须存在于系统中

9. **桌台名称**：
   - 可选
   - 如果填写，桌台必须存在于系统中
   - 仅堂食订单（用餐方式=0）需要

10. **会员编号**：
    - 可选
    - 如果填写，会员必须存在于系统中
    - 仅会员订单（订单类型=2）需要

11. **当班编号**：
    - 可选
    - 长度不超过 255 个字符

12. **桌位编号**：
    - 可选
    - 长度不超过 255 个字符

13. **商品金额**：
    - 可选
    - 如果填写，必须为数字，保留2位小数
    - 必须大于等于 0
    - 如果不填写，系统会从订单明细自动计算

14. **服务费**：
    - 可选
    - 如果填写，必须为数字，保留2位小数
    - 必须大于等于 0

15. **税费**：
    - 可选
    - 如果填写，必须为数字，保留2位小数
    - 必须大于等于 0

### 订单明细校验

1. **订单号**：
   - 必填，不能为空
   - 必须存在于订单基本信息中

2. **商品名称**：
   - 必填，不能为空
   - 商品必须存在于系统中

3. **数量**：
   - 必填，不能为空
   - 必须为整数
   - 必须大于 0

4. **单价**：
   - 必填，不能为空
   - 必须为数字，保留2位小数
   - 必须大于等于 0

5. **小计**：
   - 必填，不能为空
   - 必须为数字，保留2位小数
   - 必须等于 数量 × 单价（允许0.01的误差）

## 🔧 导入处理逻辑

### 数据关联

1. **订单基本信息**：
   - 通过 `门店名称` 查找 `shop_uuid`
   - 通过 `桌台名称` 查找 `desk_uuid`（如果提供）
   - 通过 `会员编号` 查找 `consumer_uuid`（如果提供）

2. **订单明细**：
   - 通过 `订单号` 关联订单基本信息
   - 通过 `商品名称` 查找 `product_uuid`

### 数据转换

1. **时间转换**：
   - Excel 中的日期时间格式 `YYYY-MM-DD HH:mm:ss` 转换为 Unix 时间戳（秒）
   - 示例：`2025-11-19 14:30:00` → `1734592200`

2. **金额计算**：
   - 订单明细的 `小计` = `数量` × `单价`
   - 订单基本信息的 `商品金额` = 所有订单明细的 `小计` 之和（如果 Excel 中未填写）
   - 订单基本信息的 `订单金额` = `商品金额` + `服务费` + `税费`（如果 Excel 中未填写，则从明细计算）

3. **默认值设置**：
   - `就餐人数` 默认为 1（如果为空）
   - `收银员姓名` 默认为空字符串（如果为空）
   - `当班编号` 默认为空字符串（如果为空）
   - `桌位编号` 默认为空字符串（如果为空）
   - `商品金额` 如果为空，从订单明细自动计算
   - `服务费` 默认为 0（如果为空）
   - `税费` 默认为 0（如果为空）
   - `备注` 默认为空字符串（如果为空）

### 错误处理

1. **订单号重复**：
   - 如果订单号已存在，跳过该订单
   - 在结果中记录：`订单号已存在，跳过`

2. **关联数据不存在**：
   - 门店不存在：`门店 {门店名称} 不存在`
   - 商品不存在：`商品 {商品名称} 不存在`
   - 桌台不存在：`桌台 {桌台名称} 不存在`
   - 会员不存在：`会员 {会员编号} 不存在`

3. **数据格式错误**：
   - 日期格式错误：`下单时间格式错误，应为 YYYY-MM-DD HH:mm:ss`
   - 金额格式错误：`订单金额格式错误，应为数字`
   - 数量格式错误：`数量格式错误，应为整数`

## 📌 注意事项

1. **Excel 文件必须包含两个工作表**：
   - Sheet1：订单基本信息
   - Sheet2：订单明细

2. **表头必须在第 1 行**，数据从第 2 行开始

3. **订单明细必须关联订单基本信息**：
   - 订单明细中的订单号必须在订单基本信息中存在

4. **数据顺序**：
   - 订单基本信息可以任意顺序
   - 订单明细可以任意顺序（系统会自动关联）

5. **空行处理**：
   - 空行会被自动跳过

6. **字符编码**：
   - Excel 文件使用 UTF-8 编码
