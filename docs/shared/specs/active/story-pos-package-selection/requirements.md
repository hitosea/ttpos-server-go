## 📋 概述

在收银端、点餐助手、平板、会员端、自助点餐机等终端实现套餐商品选择功能，支持固定分组和可选分组的商品选择，显示选择状态和商品加价信息，并在加购时验证分组选择是否符合套餐设置。该功能基于已有的套餐分组类型和加价功能（商家管理端），主要在前端各终端实现选择界面和价格计算逻辑。

## 🎯 产品对齐

该功能支持产品愿景中的"提升套餐灵活性"和"改善用户体验"目标，通过支持可选分组和加价显示，帮助顾客更灵活地选择套餐商品，了解价格构成，提升点餐体验，同时提高客单价。

## 📝 用户故事

**作为** 收银员/顾客  
**我想** 在选择套餐商品时，能够看到分组类型（固定/可选）、选择状态（已选 X 份、还差 X 份）、商品加价信息，并能够完成可选分组的商品选择  
**以便于** 更灵活地选择套餐商品，了解价格构成，提升点餐体验

## 功能需求

### Requirement 1: 分组类型显示

**用户故事**: 作为收银员/顾客，我想在选择套餐时看到分组类型，以便于了解哪些商品是必选的，哪些是可选的

#### 验收标准

1. **WHEN** 打开套餐选择弹窗 **THEN** 系统 **SHALL** 根据分组类型显示不同的选择界面
2. **IF** 分组类型为固定（`group_type = 0`） **THEN** 系统 **SHALL** 显示所有商品，默认选中，不可取消
3. **IF** 分组类型为可选（`group_type = 1`） **THEN** 系统 **SHALL** 显示选择状态（已选 X 份、还差 X 份），支持步进器选择

#### 具体要求

- [ ] 1.1 商品列表接口返回分组类型字段 `group_type`
- [ ] 1.2 前端根据 `group_type` 显示不同的选择界面
- [ ] 1.3 固定分组：所有商品默认选中，不可取消
- [ ] 1.4 可选分组：显示选择状态，支持选择/取消

---

### Requirement 2: 选择状态提示

**用户故事**: 作为顾客，我想看到当前已选数量和还差多少，以便于了解选择进度

#### 验收标准

1. **WHEN** 选择可选分组的商品 **THEN** 系统 **SHALL** 显示"已选 X 份"和"还差 X 份"
2. **IF** 商品数量是 2，选了 1 份 **THEN** 系统 **SHALL** 显示"已选 1 份"（不是 2 份）
3. **IF** 商品数量是 2，选 1 份 **THEN** 系统 **SHALL** 在商品数量角标显示 2（代表 1 份里有 2 杯）
4. **IF** 商品数量是 2，选 2 份 **THEN** 系统 **SHALL** 在商品数量角标显示 4（代表 2 份总共 4 杯）

#### 具体要求

- [ ] 2.1 显示"已选 X 份"：当前已选择的数量（按份数统计）
- [ ] 2.2 显示"还差 X 份"：可选数量 - 已选份数
- [ ] 2.3 商品数量角标：套餐内商品数量 × 选择份数
- [ ] 2.4 商品列表接口返回 `optional_count` 字段

---

### Requirement 3: 加价显示

**用户故事**: 作为顾客，我想看到商品的加价信息，以便于了解价格构成

#### 验收标准

1. **WHEN** 商品有加价（`add_price > 0`） **THEN** 系统 **SHALL** 显示加价金额
2. **IF** 商品加价为 0 **THEN** 系统 **SHALL** 不显示价格
3. **WHEN** 显示加价 **THEN** 系统 **SHALL** 显示正确的加价金额

#### 具体要求

- [ ] 3.1 商品列表接口返回 `add_price` 字段
- [ ] 3.2 前端只显示 `add_price > 0` 的商品价格
- [ ] 3.3 0 元加价不显示价格

---

### Requirement 4: 选择交互

**用户故事**: 作为顾客，我想通过步进器选择商品数量，以便于灵活选择

#### 验收标准

1. **WHEN** 点击可选分组的商品 **THEN** 系统 **SHALL** 显示步进器（数量为 0 时不显示）
2. **WHEN** 选中商品 **THEN** 系统 **SHALL** 显示"定制"选项
3. **IF** 是默认商品 **THEN** 系统 **SHALL** 默认+1 份
4. **IF** 是必选商品 **THEN** 系统 **SHALL** 必须保持一份（减最后一份时提示：必选商品不可删除）

#### 具体要求

- [ ] 4.1 可选类型：点击商品后出现步进器（数量为 0 时不显示）
- [ ] 4.2 可选类型：默认商品默认+1 份
- [ ] 4.3 可选类型：必选商品必须保持一份
- [ ] 4.4 固定类型：选择组内所有商品

---

### Requirement 5: 选择验证

**用户故事**: 作为顾客，我想在选择商品时得到明确的提示，以便于了解选择限制

#### 验收标准

1. **IF** 分组已选满 **THEN** 系统 **SHALL** 提示"当前已选满，请删除商品再试"
2. **IF** 点击确定时分组未选满 **THEN** 系统 **SHALL** 提示"xx 还没有选满"
3. **IF** 固定分组未选满 **THEN** 系统 **SHALL** 提示"固定分组必须选择所有商品"

#### 具体要求

- [ ] 5.1 前端验证：分组已选满时提示
- [ ] 5.2 前端验证：分组未选满时提示
- [ ] 5.3 后端验证：加购前验证分组选择是否符合套餐设置

---

### Requirement 6: 价格计算

**用户故事**: 作为顾客，我想看到正确的套餐价格，以便于了解总价

#### 验收标准

1. **WHEN** 套餐包含加价商品 **THEN** 系统 **SHALL** 计算套餐单价 = 套餐原始定价 + Σ(子商品加价 × 子商品数量)
2. **WHEN** 加购到购物车 **THEN** 系统 **SHALL** 在 `sale_order_product` 表中正确记录 `add_price` 字段
3. **WHEN** 查询购物车 **THEN** 系统 **SHALL** 返回正确的套餐价格（包含加价）

#### 具体要求

- [ ] 6.1 数据库：`sale_order_product` 表增加 `add_price` 字段
- [ ] 6.2 子商品：记录单商品加价金额
- [ ] 6.3 套餐主商品：记录所有子商品加价总和
- [ ] 6.4 价格计算：套餐单价 = 套餐原始定价 + Σ(子商品加价 × 子商品数量)
- [ ] 6.5 购物车详情接口返回正确的套餐价格

---

### Requirement 7: 加购接口参数传递

**用户故事**: 作为前端开发者，我想在加购时传递子商品的加价信息，以便于后端正确计算价格

#### 验收标准

1. **WHEN** 前端传递套餐加购请求 **THEN** 系统 **SHALL** 支持 `add_price` 字段
2. **WHEN** 加价参数传递到后端 **THEN** 系统 **SHALL** 正确保存到 `sale_order_product` 表

#### 具体要求

- [ ] 7.1 `ProductRequest` 结构体增加 `add_price` 字段
- [ ] 7.2 `ProductParams` 结构体增加 `AddPrice` 字段
- [ ] 7.3 加价参数正确传递到商品创建流程
- [ ] 7.4 加价金额正确保存到数据库

---

### Requirement 8: 分组选择验证

**用户故事**: 作为系统，我想在加购时验证分组选择是否符合套餐设置，以便于保证数据一致性

#### 验收标准

1. **WHEN** 固定分组加购 **THEN** 系统 **SHALL** 验证分组内所有商品是否都已选择
2. **WHEN** 可选分组加购 **THEN** 系统 **SHALL** 验证已选商品数量是否等于 `optional_count`
3. **IF** 验证失败 **THEN** 系统 **SHALL** 返回明确的错误提示

#### 具体要求

- [ ] 8.1 固定分组验证：验证是否包含所有商品
- [ ] 8.2 可选分组验证：验证已选数量是否等于 `optional_count`
- [ ] 8.3 验证逻辑在构建商品参数之前执行
- [ ] 8.4 验证失败时返回明确的错误提示
- [ ] 8.5 错误提示包含分组名称和具体错误信息

## 非功能需求

### 性能要求

- 商品列表接口响应时间 < 200ms
- 套餐加购接口响应时间 < 500ms（不含数据库操作）

### 兼容性要求

- 现有订单数据兼容：`add_price` 字段默认值为 0
- 现有套餐配置兼容：固定分组保持现有行为

### 安全性要求

- 加购接口需要验证订单状态
- 加购接口需要验证商品库存
- 加购接口需要验证分组选择

## 验收标准汇总

### AC1: 分组类型显示

**Given** 选择套餐商品  
**When** 打开套餐选择弹窗  
**Then** 系统 **SHALL** 根据分组类型显示不同的选择界面

### AC2: 选择状态显示

**Given** 可选分组  
**When** 选择商品  
**Then** 系统 **SHALL** 显示"已选 X 份"、"还差 X 份"、商品数量角标

### AC3: 加价显示

**Given** 套餐商品有加价  
**When** 显示商品列表  
**Then** 系统 **SHALL** 只显示加价 > 0 的商品价格

### AC4: 选择交互

**Given** 可选分组  
**When** 点击商品  
**Then** 系统 **SHALL** 显示步进器、定制选项，默认商品默认+1 份

### AC5: 选择验证

**Given** 可选分组  
**When** 选择商品  
**Then** 系统 **SHALL** 在分组已选满或未选满时提示

### AC6: 价格计算

**Given** 套餐商品包含加价  
**When** 加购到购物车  
**Then** 系统 **SHALL** 正确计算套餐价格并保存加价信息

### AC7: 加购接口参数传递

**Given** 前端传递套餐加购请求  
**When** 请求中包含子商品的加价信息  
**Then** 系统 **SHALL** 正确传递并保存加价参数

### AC8: 分组选择验证

**Given** 套餐加购请求  
**When** 提交加购  
**Then** 系统 **SHALL** 验证分组选择是否符合套餐设置
