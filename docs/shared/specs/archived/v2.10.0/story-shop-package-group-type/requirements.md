## 📋 概述

在套餐商品的分组功能中增加**分组类型**和**商品加价**两个核心能力，支持商家灵活配置套餐。商家可以设置固定分组（默认）或可选分组，对于可选分组可以设置需要选择多少个商品（如"3 选 1"、"5 选 2"等），同时支持为每个分组商品设置加价金额。该功能旨在提升套餐灵活性，满足商家多样化的套餐配置需求，增强用户体验，提高客单价。

## 🎯 产品对齐

该功能支持产品愿景中的"提升商家营销能力"和"增强用户体验"目标，通过灵活的套餐配置，帮助商家创建更符合顾客需求的套餐组合，减少 SKU 数量，提高客单价。

## 📝 用户故事

**作为** 商户管理员  
**我想** 在套餐配置中设置可选分组和商品加价  
**以便于** 创建更灵活的套餐组合，满足不同顾客需求，提高客单价

## 功能需求

### Requirement 1: 分组类型设置

**用户故事**: 作为商户管理员，我想在创建或编辑套餐时设置分组类型，以便于区分固定分组和可选分组

#### 验收标准

1. **WHEN** 创建或编辑套餐分组 **THEN** 系统 **SHALL** 提供"分组类型"选项，默认选择"固定"
2. **IF** 选择"可选"类型 **THEN** 系统 **SHALL** 显示"可选数量"输入框（默认 1）
3. **IF** 选择"固定"类型 **THEN** 系统 **SHALL** 隐藏"可选数量"输入框，分组内所有商品必选

#### 具体要求

- [ ] 1.1 在套餐分组配置界面增加"分组类型"选择器（固定/可选）
- [ ] 1.2 分组类型默认值为"固定"（0）
- [ ] 1.3 选择"可选"类型时，显示"可选数量"输入框
- [ ] 1.4 选择"固定"类型时，隐藏"可选数量"输入框
- [ ] 1.5 数据库字段 `group_type`：0-固定，1-可选
- [ ] 1.6 数据库字段 `optional_count`：可选数量，默认 1

---

### Requirement 2: 可选数量设置

**用户故事**: 作为商户管理员，我想为可选分组设置需要选择多少个商品，以便于控制顾客的选择范围

#### 验收标准

1. **IF** 设置可选数量 **THEN** 系统 **SHALL** 验证可选数量 <= 分组内商品总数
2. **IF** 必选或默认商品数量（去重）大于可选数量 **THEN** 系统 **SHALL** 提示错误："必选或默认不可大于可选数量"
3. **IF** 可选数量大于分组内商品总数 **THEN** 系统 **SHALL** 提示错误："可选数量不能大于分组内商品总数"

#### 具体要求

- [ ] 2.1 可选数量输入框支持数字输入，最小值为 1
- [ ] 2.2 实时验证可选数量不能大于分组内商品总数
- [ ] 2.3 验证必选或默认商品数量（去重）不能大于可选数量
- [ ] 2.4 验证失败时显示错误提示，阻止保存
- [ ] 2.5 固定分组时，`optional_count` 应等于分组内商品总数（自动计算）

---

### Requirement 3: 商品加价设置

**用户故事**: 作为商户管理员，我想为套餐分组中的商品设置加价金额，以便于引导顾客选择高价值商品

#### 验收标准

1. **WHEN** 配置套餐分组商品 **THEN** 系统 **SHALL** 提供加价输入框，默认值为 0
2. **IF** 设置加价金额 **THEN** 系统 **SHALL** 验证加价金额必须 >= 0
3. **IF** 加价金额为负数 **THEN** 系统 **SHALL** 提示错误："加价金额不能为负数"

#### 具体要求

- [ ] 3.1 在套餐分组商品配置中增加"加价"输入框
- [ ] 3.2 加价金额默认值为 0
- [ ] 3.3 加价金额支持小数，精度为 2 位
- [ ] 3.4 验证加价金额 >= 0
- [ ] 3.5 数据库字段 `add_price`：DECIMAL(10,2)，默认 0.00
- [ ] 3.6 加价金额会在套餐总价基础上累加

---

### Requirement 4: 必选与默认设置

**用户故事**: 作为商户管理员，我想在可选分组中设置某些商品为必选或默认选中，以便于引导顾客选择

#### 验收标准

1. **WHEN** 配置可选分组商品 **THEN** 系统 **SHALL** 提供"必选"和"默认"选项
2. **IF** 不设置必选和默认 **THEN** 系统 **SHALL** 默认不设置必选和默认选中
3. **IF** 必选或默认商品数量（去重）大于可选数量 **THEN** 系统 **SHALL** 提示错误："必选或默认不可大于可选数量"

#### 具体要求

- [ ] 4.1 在可选分组商品配置中增加"必选"复选框
- [ ] 4.2 在可选分组商品配置中增加"默认"复选框
- [ ] 4.3 默认不设置必选和默认选中
- [ ] 4.4 验证必选或默认商品数量（去重）不能大于可选数量
- [ ] 4.5 必选商品在顾客选择时自动选中且不可取消

---

### Requirement 5: 商品数量显示

**用户故事**: 作为商户管理员，我想查看套餐分组中每个商品的数量，以便于了解套餐配置

#### 验收标准

1. **WHEN** 查看套餐分组商品 **THEN** 系统 **SHALL** 显示商品的实际数量
2. **Example**: 商品 A 数量是 2，商品 B 数量是 1，则显示 2 和 1

#### 具体要求

- [ ] 5.1 在套餐分组商品列表中显示每个商品的数量
- [ ] 5.2 商品数量支持小数显示（如 1.5）
- [ ] 5.3 商品数量在创建和编辑时都可以修改

---

### Requirement 6: 可选数量计算逻辑

**用户故事**: 作为商户管理员，我想了解可选分组的数量计算逻辑，以便于正确配置套餐

#### 验收标准

1. **Given** 可选分组，设置可选数量为 3  
   **When** 顾客选择商品  
   **Then** 系统 **SHALL** 计算总数量为：商品 A 数量 × 选择份数 + 商品 B 数量 × 选择份数  
   **Example**: 如果可选 3 份，商品 A 选 2 份（数量 2），商品 B 选 1 份（数量 1），则总共 5 杯饮料（2×2 + 1×1）

#### 具体要求

- [ ] 6.1 可选分组的数量计算逻辑：每个商品的数量 × 选择的份数，然后累加
- [ ] 6.2 在订单创建时正确计算可选分组的商品数量
- [ ] 6.3 在订单详情中正确显示可选分组的商品数量

---

### Requirement 7: API 接口扩展

**用户故事**: 作为开发者，我想在 API 接口中支持分组类型和加价字段，以便于前后端数据交互

#### 验收标准

1. **WHEN** 调用创建套餐接口 `/shop/product/add [POST]` **THEN** 系统 **SHALL** 支持 `group_type`、`optional_count`、`add_price` 字段
2. **WHEN** 调用编辑套餐接口 `/shop/product/edit [POST]` **THEN** 系统 **SHALL** 支持上述字段
3. **WHEN** 调用商品详情接口 `/shop/product/detail [GET]` **THEN** 系统 **SHALL** 返回上述字段

#### 具体要求

- [ ] 7.1 `ProductShopAddPackageGroupReq` 增加 `group_type`、`optional_count` 字段
- [ ] 7.2 `ProductShopAddPackageGroupProductReq` 增加 `add_price` 字段
- [ ] 7.3 `ProductShopEditPackageGroupReq` 同步增加上述字段
- [ ] 7.4 `ProductShopEditPackageGroupProductReq` 同步增加 `add_price` 字段
- [ ] 7.5 商品详情响应中返回分组类型、可选数量、加价字段
- [ ] 7.6 API 参数验证：`group_type` 为 0 或 1，`optional_count` >= 1，`add_price` >= 0

---

### Requirement 8: 数据库迁移

**用户故事**: 作为开发者，我想通过数据库迁移添加新字段，以便于平滑升级现有数据

#### 验收标准

1. **WHEN** 执行数据库迁移 **THEN** 系统 **SHALL** 为现有数据设置合理的默认值
2. **IF** 现有套餐分组 **THEN** 系统 **SHALL** 默认为"固定分组"（`group_type=0`）
3. **IF** 现有商品加价 **THEN** 系统 **SHALL** 默认为 0（`add_price=0`）

#### 具体要求

- [ ] 8.1 创建数据库迁移文件，为 `ttpos_product_package_group` 表增加字段
- [ ] 8.2 创建数据库迁移文件，为 `ttpos_product_package_group_item` 表增加字段
- [ ] 8.3 迁移时设置现有数据的默认值：`group_type=0`，`optional_count=1`，`add_price=0.00`
- [ ] 8.4 迁移文件支持回滚
- [ ] 8.5 迁移前检查字段是否存在，避免重复添加

## 🔒 数据验证规则

### 分组类型验证

- `group_type`：必须为 0（固定）或 1（可选）
- `optional_count`：必须 >= 1，且 <= 分组内商品总数
- 固定分组时，`optional_count` 应等于分组内商品总数

### 加价验证

- `add_price`：必须 >= 0
- `add_price`：支持小数，精度为 2 位

### 必选验证

- 必选或默认商品数量（去重）不能大于可选数量
- 必选数量不能大于分组内商品总数
