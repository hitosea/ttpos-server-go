## 🎯 背景和动机

### 问题描述

新管理端（Shop）的门店汇总统计功能存在以下问题：

1. **缺少平均值对比维度**：营业数据汇总、退款金额汇总、支付方式汇总表格只有各项数据的逐行展示和总计，缺少平均值统计行，用户无法直观对比各门店/时段的平均表现，难以快速发现异常数据
2. **退款分析不够细化**：退款金额汇总表只有退款金额和退款单数，缺少"平均退款额"等更精细的分析指标，无法评估单笔退款的严重程度

### 业务价值

- **数据分析能力提升**：平均值对比让门店表现一目了然，方便发现异常门店
- **运营决策支持**：通过平均退款额等指标评估门店运营质量，辅助管理决策
- **报表导出更完整**：导出文档包含平均值统计，减少手动计算工作量

## 💡 解决方案概述

### 方案描述

在营业数据汇总、退款金额汇总、支付方式汇总三个表格的底部增加固定的"平均值"行，显示各列数据的平均值（总和/个数）。平均值基于当前筛选条件下的全部数据计算，而非当页数据。同时在退款金额汇总表增加"平均退款额"字段。导出功能同步支持平均值行的导出。

### 核心功能点

1. **表格平均值行**：营业数据汇总、退款金额汇总、支付方式汇总表格底部增加"平均值"行，计算公式为"该列数值总和/该列个数"，基于筛选后全部数据计算
2. **退款表新增字段**：退款金额汇总表头增加"平均退款额"列，计算公式为"退款金额/退款单数"
3. **导出平均值支持**：导出的 Excel 文档在最后一行追加"平均值"记录
4. **营业数据表新增业绩分类字段**（位于"现金AC"列后）：
   - **到店业绩**：堂食 + 外带的订单总金额（扣除退款金额、反结账金额）
   - **到店订单数**：堂食 + 外带的订单总单数（扣除整单退订单，部分退订单纳入统计）
   - **外卖业绩**：外送 + 外卖（Grab、LINE MAN）的订单总金额（已取消的第三方外卖订单不计入）
   - **外卖订单数**：外送 + 外卖（Grab、LINE MAN）的订单总单数（已取消的第三方外卖订单不计入）

### 风险识别

**潜在风险**：
1. 大数据量下平均值实时计算可能影响响应速度
2. 平均值精度和小数位数需统一规范
3. 订单渠道分类可能需要与现有统计口径对齐（堂食/外带/外送/第三方外卖的定义）

**缓解措施**：
1. 后端接口优化，考虑在数据库层面完成聚合计算，避免全量数据传输
2. 与产品确认数值精度规范（建议保留2位小数）
3. 复用现有订单渠道分类逻辑，确保与其他报表口径一致

## 📝 附录

### User Story（初稿）

**作为** 店长/运营人员/财务人员
**我想** 在门店汇总统计的营业数据、退款金额、支付方式表格中查看各列的平均值，并在退款汇总中查看平均退款额，同时在营业数据汇总中按渠道分类查看到店业绩（堂食+外带）和外卖业绩（外送+第三方外卖）
**以便于** 快速对比各门店/时段的平均表现，分析不同渠道的业绩贡献，发现异常数据，支持运营决策

### AC 验收标准（初稿）

1. **WHEN** 用户查看营业数据汇总/退款金额汇总/支付方式汇总表格 **THEN** 表格底部 **SHALL** 固定显示"平均值"行，展示各数值列的平均值（总和/个数）
2. **WHEN** 用户使用筛选条件筛选数据 **THEN** 平均值 **SHALL** 基于筛选后的全部数据重新计算，而非仅当页数据
3. **WHEN** 用户查看退款金额汇总表 **THEN** 表头 **SHALL** 新增"平均退款额"列，数值=退款金额/退款单数
4. **WHEN** 用户导出营业数据汇总/退款金额汇总/支付方式汇总表格 **THEN** 导出的 Excel 文档 **SHALL** 在最后一行包含"平均值"记录
5. **WHEN** 用户查看营业数据汇总表（明细表/汇总表） **THEN** 表头在"现金AC"后 **SHALL** 依次显示"到店业绩"、"到店订单数"、"外卖业绩"、"外卖订单数"四列
6. **WHEN** 营业数据汇总表显示数据 **THEN** "到店业绩" **SHALL** 等于堂食订单金额+外带订单金额-退款金额-反结账金额，"到店订单数" **SHALL** 等于堂食订单数+外带订单数-整单退订单数（部分退订单纳入统计）
7. **WHEN** 营业数据汇总表显示数据 **THEN** "外卖业绩" **SHALL** 等于外送订单金额+第三方外卖（Grab、LINE MAN等）订单金额，已取消的第三方外卖订单 **SHALL NOT** 计入
8. **WHEN** 营业数据汇总表显示数据 **THEN** "外卖订单数" **SHALL** 等于外送订单数+第三方外卖订单数，已取消的第三方外卖订单 **SHALL NOT** 计入
