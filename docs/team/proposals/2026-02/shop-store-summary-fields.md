## 🎯 背景和动机

### 问题描述

当前门店汇总统计（营业数据汇总-明细表/汇总表）存在以下问题：

1. **字段名称不符合行业习惯**：如"订单金额"、"实付金额"、"订单数量"等名称，与餐饮行业常用术语（总营业额、实收金额、TC/AC）不一致，影响数据理解效率
2. **缺少现金统计维度**：无法快速查看现金收款的订单数、金额和客单价，不便于财务对账
3. **店铺名称格式不清晰**：缺少店铺编号，多店铺场景下难以快速定位
4. **字段排序不合理**：重要指标未优先展示

### 业务价值

- **数据可读性提升**：字段名称符合行业习惯，店长和运营人员能更快理解数据含义
- **运营分析效率提升**：新增现金统计字段，方便财务人员进行现金对账和分析
- **合规需求**：满足财务审计对现金流水的统计要求

### 目标用户

- [x] 商户管理员
- [x] 运营人员
- [x] 财务人员

## 💡 解决方案概述

### 方案描述

对门店汇总统计的明细表和汇总表进行优化，包括：调整表头字段名称使其符合行业习惯、新增现金统计维度（现金TC、现金金额、现金AC）、优化店铺名称显示格式（编号+名称）、调整字段排序。同时同步调整 Excel 导出功能，确保导出数据与页面展示一致。

### 核心功能点

1. **表头字段名称修改**
   - "门店名称" → "店铺名称"
   - "订单金额" → "总营业额"
   - "实付金额" → "实收金额"
   - "订单数量（单）" → "TC"
   - "订单金额单均" → "AC"

2. **新增现金统计字段**
   - **现金TC**：收款方式为 Cash 的订单总数
   - **现金金额**：收款方式为 Cash 的订单总金额
   - **现金AC**：现金金额 / 现金TC（保留2位小数）

3. **表头字段排序调整**
   按以下顺序展示：
   > 营业日 | 店铺名称 | 总营业额 | 实收金额 | TC | AC | 现金TC | 现金金额 | 现金AC | 用餐人数（人） | 消费桌数（桌） | 平均客单价 | 订单金额人均 | 订单金额单均 | 实付金额单均 | 点餐订单金额 | 桌台订单金额 | 外送订单金额

4. **店铺名称格式优化**
   - 格式：`{店铺编号} {商家名称}`
   - 示例：`001 华莱士xxx门店`
   - 排序规则：
     - 未设置店铺编号的排在最前，按店铺创建时间顺序排序
     - 已设置店铺编号的，编号优先数字（0-9）再字母（a-z）；编号相同时按店铺创建时间顺序排序

5. **导出功能同步调整**
   - Excel 导出的表头名称、字段顺序、新增字段与页面展示完全一致

## 📝 附录

### User Story（初稿）

**作为** 店长/商户管理员
**我想** 在门店汇总统计中看到符合行业习惯的字段名称、完整的现金统计数据、以及带编号的店铺名称
**以便于** 更快理解营业数据、进行财务对账、快速定位多店铺数据

### AC 验收标准（初稿）

1. **WHEN** 查看门店汇总统计明细表/汇总表 **THEN** 系统 **SHALL** 按新的字段名称和顺序展示数据
2. **WHEN** 表格中存在现金支付订单 **THEN** 系统 **SHALL** 正确计算并展示现金TC、现金金额、现金AC
3. **WHEN** 店铺设置了编号 **THEN** 系统 **SHALL** 以"编号 名称"格式显示店铺名称
4. **WHEN** 多店铺排序 **THEN** 系统 **SHALL** 按规则排序：无编号店铺优先（按创建时间顺序），有编号店铺按编号排序（数字优先于字母，编号相同时按创建时间顺序）
5. **WHEN** 导出 Excel **THEN** 系统 **SHALL** 导出与页面一致的字段名称、顺序和数据

### 字段名称对照表

| 原字段名 | 新字段名 |
|---------|---------|
| 门店名称 | 店铺名称 |
| 订单金额 | 总营业额 |
| 实付金额 | 实收金额 |
| 订单数量（单） | TC |
| 订单金额单均 | AC |

### 新增字段定义

| 字段名 | 计算逻辑 | 说明 |
|-------|---------|------|
| 现金TC | COUNT(payment_method='Cash') | 现金支付订单数 |
| 现金金额 | SUM(amount WHERE payment_method='Cash') | 现金支付总金额 |
| 现金AC | 现金金额 / 现金TC | 保留2位小数 |
