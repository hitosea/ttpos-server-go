## 📝 附录

### User Story（初稿）

[如果已有初步的 User Story，可以先写在这里]

**作为** 开发者  
**我想** 新增 GetItemStockByBin 服务  
**以便于** 根据仓库和商品代码查询货位库存信息

### AC 验收标准（初稿）

[如果已有初步的验收标准，可以先写在这里]

1. **WHEN** 传入有效的 Warehouse 参数 **THEN** 系统 **SHALL** 返回该仓库的所有商品库存按货位分组的信息
2. **IF** 同时传入 item_code 参数 **THEN** 系统 **SHALL** 只返回指定商品的库存信息
3. **WHEN** Warehouse 参数为空 **THEN** 系统 **SHALL** 返回参数错误
4. **WHEN** 调用已有的 Bin 查询服务失败 **THEN** 系统 **SHALL** 返回相应的错误信息
