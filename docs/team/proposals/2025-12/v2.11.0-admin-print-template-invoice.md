## 🎯 背景和动机

### 问题描述

当前自定义打印模板不支持发票打印功能，商家在需要打印发票时无法使用统一的模板管理体系，需要单独处理发票打印逻辑。特别是在需要打印多种票据（结账单、发票等）的场景下，缺乏统一的管理入口和自定义能力，影响了商家的使用体验和运营效率。

### 业务价值

- 提供统一的票据管理入口，简化商家操作流程
- 支持发票的自定义配置，满足不同商家的个性化需求
- 提升票据打印的灵活性和可扩展性
- 增强产品竞争力，满足合规要求

## 💡 解决方案概述

### 方案描述

在现有的新管理端自定义打印模板功能基础上，增加发票模板类型。发票模板支持基础字段（店铺编号、发票编号、统一信用代码、交易单号等）和自定义内容（票据名称、发票信息、注意事项等）的编辑。提供可视化编辑界面，支持拖拽排序、重复添加、分割线/空行插入等高级编辑能力，同时保留默认模板供商家快速使用。

### 核心功能点

1. **发票专属字段支持**
   - 发票编号、统一信用代码、交易单号、店铺编号
   - 价格说明、发票信息、注意事项
   - 可编辑票据名称

2. **高级票据模板功能**
   - 可视化编辑区：左侧模板选择项 + 右侧样式编辑
   - 拖拽排序：调整打印项顺序
   - 重复添加：单项最多可重复5次
   - 分割线/空行插入：优化打印布局

3. **模板管理功能**
   - 创建自定义发票模板
   - 使用/预览/删除模板
   - 恢复默认模板
   - 云平台开关控制高级功能

4. **旧商家后台兼容**
   - 支持预览和使用自定义模板
   - 调整模板需前往桌面端操作

### 风险识别

**潜在风险**：
1. **旧商家后台兼容性**：旧系统需要能正确预览新模板，但不支持编辑
2. **拖拽交互复杂度**：可能需要引入专门的拖拽库，增加前端复杂度
3. **打印机兼容性**：不同打印机对复杂布局的支持程度不同
4. **数据迁移**：现有的结账单模板和新的发票模板需要共存

**缓解措施**：
1. 提前做旧商家后台预览测试，确保只读模式正常工作
2. 选用成熟的 Vue 拖拽库（如 Vuedraggable），降低开发风险
3. 在打印前做兼容性处理，提供降级方案
4. 设计数据库表结构时预留扩展字段，支持多种票据类型

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在新管理端创建和编辑发票打印模板  
**以便于** 能够按照商家需求打印符合规范的发票，满足合规要求并提升客户体验

### AC 验收标准（初稿）

基于 DooTask #37498 任务内容：

#### 一、左侧区（模板选择项）

1. **WHEN** 用户点击左侧模板项 **THEN** 系统 **SHALL** 在编辑区显示对应配置项，并高亮选中项
2. **IF** 某字段内容为空（无数据时） **THEN** 系统 **SHALL** 不打印该项
3. **WHEN** 发票编号、统一信用代码、交易单号、店铺编号无内容时 **THEN** 系统 **SHALL** 不打印这些字段
4. **WHEN** 用户编辑票据名称 **THEN** 系统 **SHALL** 允许修改文字内容

**差异性说明**：对比结账单，发票模板增加了店铺编号、发票编号、统一信用代码、交易单号、价格说明、可编辑票据名称、发票信息、注意事项等字段。

#### 二、右侧区（样式编辑）

1. **WHEN** 用户点击"分割线"按钮 **THEN** 系统 **SHALL** 在选中项下方插入水平分割线
2. **WHEN** 用户点击"空行插入"按钮 **THEN** 系统 **SHALL** 在选中项上方或下方插入空行（字号正常大小）
3. **IF** 项目可删除 **THEN** 系统 **SHALL** 显示删除按钮
4. **WHEN** 用户输入自定义文字 **THEN** 系统 **SHALL** 限制最多500字符
5. **IF** 自定义文字对某语言未翻译 **THEN** 系统 **SHALL** 在该语言下不打印该文字
6. **IF** 自定义图片未上传 **THEN** 系统 **SHALL** 不打印该图片

**注意**：商品项默认开启，不可关闭。

#### 三、编辑区

1. **WHEN** 用户选择某项 **THEN** 系统 **SHALL** 仅高亮该项，其他项取消高亮
2. **WHEN** 用户编辑高级票据模板名称 **THEN** 系统 **SHALL** 限制1-20字符
3. **IF** 用户未填写模板名称并尝试保存 **THEN** 系统 **SHALL** 显示 Toast 提示"请填写模板名称"
4. **WHEN** 用户拖动编辑区内的项/组 **THEN** 系统 **SHALL** 允许任意调整位置（默认模板不可拖动）
5. **WHEN** 单项被重复添加第三次时 **THEN** 系统 **SHALL** 弹窗提示"您已经多次添加【xxx】信息，仍然要继续添加吗？"
6. **IF** 单项已被添加5次 **THEN** 系统 **SHALL** 禁止再次添加该项

**注意**：高级票据模板才有拖动排序、重复添加等高级功能。

#### 四、自定义打印规则

1. **WHEN** 用户点击"恢复默认"按钮 **THEN** 系统 **SHALL** 恢复模板到最初的默认样式
2. **WHEN** 用户鼠标移入未在使用的模板 **THEN** 系统 **SHALL** 显示"使用模板"按钮
3. **WHEN** 用户点击删除高级票据模板 **THEN** 系统 **SHALL** 弹窗提示"是否删除票据"（默认模板不可删除）
4. **IF** 模板正在使用中 **THEN** 系统 **SHALL** 禁止删除该模板
5. **IF** 云平台未开启高级票据模板 **THEN** 系统 **SHALL** 不显示高级票据自定义项（云平台默认关闭）
6. **WHEN** 旧商家后台查看发票模板 **THEN** 系统 **SHALL** 仅允许预览和使用，调整需前往桌面端操作
