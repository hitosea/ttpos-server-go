## 🎯 背景和动机

### 问题描述

在 Kiosk 自助点餐机终端中，首页是用户进入点餐流程的第一个界面，需要提供清晰、友好的引导和配置选项。当前缺少统一的首页功能模块，无法有效展示商家信息、引导用户选择用餐方式、切换语言等基础功能。

**当前痛点**：

- 用户登录后缺少统一的首页入口，无法快速了解商家信息和功能
- 无法在首页选择用餐方式（堂食/外带），影响后续订单流程
- 缺少多语言切换入口，国际化支持不完善
- 无法在首页呼叫服务员，用户体验不完整
- 缺少轮播广告展示功能，无法进行营销推广

### 业务价值

通过实现首页功能模块，可以带来以下业务价值：

- **提升用户体验**：提供清晰的首页入口，引导用户快速进入点餐流程
- **支持多场景**：通过用餐方式选择，支持堂食和外带两种业务场景
- **国际化支持**：通过多语言切换，满足不同地区用户的语言需求
- **营销推广**：通过轮播广告展示，提升商家营销效果
- **服务支持**：通过呼叫服务员功能，提供人工服务支持

## 💡 解决方案概述

### 方案描述

开发 Kiosk 自助点餐机首页功能模块，提供统一的首页入口，包含轮播广告展示、用餐方式选择、多语言切换、呼叫服务员等核心功能。首页作为用户登录后的第一个界面，需要提供清晰的信息展示和操作引导。

**核心流程**：

1. **首页展示**：用户登录成功后，进入首页，展示轮播广告、商家信息
2. **用餐方式选择**：用户选择用餐方式（堂食/外带），影响后续订单流程
3. **语言切换**：用户选择界面语言（简体中文/繁体中文/英文等），影响商品名称、描述等显示
4. **呼叫服务员**：用户需要帮助时，可以呼叫服务员
5. **进入点餐**：完成基础配置后，进入商品浏览和点餐流程

### 核心功能点

1. **轮播广告展示**
   - 支持图片和视频轮播
   - 可配置轮播内容（通过商家后台配置）
   - 自动播放和手动切换
   - 点击广告可跳转到指定页面（可选）

2. **用餐方式选择**
   - 提供堂食和外带两种选择
   - 选择后影响后续订单的取餐方式
   - 支持在订单确认页面修改

3. **多语言切换**
   - 支持简体中文、繁体中文、英文等多种语言
   - 切换后影响界面文字、商品名称、描述等
   - 语言列表从商家后台配置获取
   - 支持默认语言设置

4. **呼叫服务员功能**
   - 提供呼叫服务员按钮
   - 呼叫后通知相关服务员（通过 KDS、Assistant 等终端）
   - 显示呼叫成功提示
   - 支持取消呼叫

5. **基本信息获取**
   - 获取商家基本信息（名称、Logo等）
   - 获取设备信息（设备ID、设备备注等）
   - 获取语言列表配置
   - 获取轮播广告配置

## 📊 初步评估

### 技术复杂度

- [ ] **低**：纯 UI 调整，无业务逻辑变更
- [x] **中**：需要前后端联调，基础业务逻辑
- [ ] **高**：涉及架构调整、第三方集成、复杂算法

**说明**：

- 需要参考其他终端的 base 接口实现（Cashier、Tablet、Assistant等）
- 需要集成呼叫服务员服务（参考 Tablet、H5 等终端的实现）
- 需要从商家后台获取配置信息（轮播广告、语言列表等）
- UI 需要适配大屏触摸交互

- 测试与联调：0.5-1 天

### 风险识别

**潜在风险**：

1. **配置数据同步风险**：轮播广告、语言列表等配置需要从商家后台同步，可能存在数据不一致问题
2. **呼叫服务员通知风险**：呼叫服务员需要通知到相关终端，可能存在通知失败或延迟问题
3. **多语言数据完整性风险**：商品名称、描述等需要多语言数据，可能存在翻译不完整或错误
4. **大屏适配风险**：不同品牌、型号的自助点餐机分辨率差异，可能影响显示效果

**缓解措施**：

1. 实现配置缓存机制，定期刷新配置数据；增加配置变更通知机制
2. 实现呼叫服务的重试机制和状态查询；增加呼叫日志记录
3. 建立多语言数据管理流程，确保数据完整性；提供多语言数据缺失时的降级方案（显示默认语言）
4. 在多种设备上进行测试，建立设备兼容性清单；使用响应式布局，支持不同分辨率适配

### User Story（初稿）

**作为** 顾客  
**我想** 在自助点餐机首页看到商家信息和轮播广告  
**以便于** 了解商家信息和最新活动

**作为** 顾客  
**我想** 在首页选择用餐方式（堂食/外带）  
**以便于** 根据我的需求快速进入点餐流程

**作为** 顾客  
**我想** 在首页切换界面语言  
**以便于** 使用我熟悉的语言进行点餐

**作为** 顾客  
**我想** 在首页呼叫服务员  
**以便于** 在需要帮助时快速获得人工服务

**作为** 门店运营人员  
**我想** 在商家后台配置首页轮播广告和语言列表  
**以便于** 进行营销推广和国际化支持

### AC 验收标准（初稿）

1. **WHEN** 用户登录成功 **THEN** 系统 **SHALL** 显示首页，包含轮播广告、用餐方式选择、语言切换、呼叫服务员等功能入口

2. **WHEN** 用户进入首页 **THEN** 系统 **SHALL** 从商家后台获取轮播广告配置，支持图片和视频轮播，自动播放

3. **WHEN** 用户选择用餐方式（堂食/外带） **THEN** 系统 **SHALL** 保存选择，影响后续订单的取餐方式

4. **WHEN** 用户切换语言 **THEN** 系统 **SHALL** 更新界面文字、商品名称、描述等，支持简体中文、繁体中文、英文等多种语言

5. **WHEN** 用户点击呼叫服务员 **THEN** 系统 **SHALL** 发送呼叫通知到相关终端（KDS、Assistant等），显示呼叫成功提示

6. **WHEN** 用户完成首页配置 **THEN** 系统 **SHALL** 允许用户进入商品浏览和点餐流程

7. **WHEN** 商家在后台配置轮播广告和语言列表 **THEN** 系统 **SHALL** 在首页展示最新配置，支持实时更新

8. **WHEN** 网络异常或配置获取失败 **THEN** 系统 **SHALL** 显示友好提示，支持重试或使用默认配置
