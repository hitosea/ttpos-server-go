## 🎯 背景和动机

### 问题描述

当前 Grab 外卖平台接入 TTPOS 后，外卖订单需要同步到 ERPNext 的 POS Invoice 中。为了能够追溯和识别外卖订单的来源信息，需要在 POS Invoice 中记录：
1. **外卖订单号**：第三方平台（如 Grab）的订单号
2. **外卖平台提供商**：标识订单来自哪个外卖平台（如 Grab）

目前 POS Invoice 缺少这些字段，无法区分店内订单和外卖订单，也无法追溯第三方平台的订单号，影响后续的对账和数据分析。

### 业务价值

- **订单追溯**：能够通过第三方订单号快速定位和查询外卖订单
- **数据统计**：区分店内订单和外卖订单，支持按平台进行数据分析
- **对账支持**：为后续与第三方平台对账提供数据基础
- **业务扩展**：为未来接入更多外卖平台（如 Foodpanda、Line Man 等）做好准备

## 💡 解决方案概述

### 方案描述

在 ERPNext 的 POS Invoice DocType 中新增两个自定义字段（custom_ 前缀，Data 类型）：
1. `custom_takeout_order_no`：存储第三方外卖平台的订单号
2. `custom_takeout_provider`：存储外卖平台提供商标识（如 "grab"）

同时更新 TTPOS 系统的相关代码：
1. 在 `SavePosInvoice` 的 protobuf 定义中增加这两个可选字段
2. 在 `SavePosInvoice` 的实现逻辑中支持这两个字段的传递和保存
3. 更新 POS Invoice 的 DTO 结构，包含这两个新字段

### 核心功能点

1. **ERPNext 自定义字段创建**
   - 创建 `01_pos_invoice_takeout_order_no.json` 迁移文件
   - 创建 `02_pos_invoice_takeout_provider.json` 迁移文件
   - 字段类型：Data（字符串）
   - 字段前缀：custom_

2. **Protobuf 接口扩展**
   - 在 `SavePosInvoiceReq` 中增加 `takeout_order_no` 和 `takeout_provider` 可选字段
   - 保持向后兼容，字段为可选

3. **业务逻辑实现**
   - 在 `buildPosInvoice` 方法中支持新字段的传递
   - 更新 POS Invoice DTO 结构，包含新字段

4. **数据同步**
   - 外卖订单支付完成时，将 `MemberSaleOrder.RelatedOrderNo` 同步到 `custom_takeout_order_no`
   - 将 `MemberSaleOrder.RelatedOrderType`（如 "grab"）同步到 `custom_takeout_provider`

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在 ERPNext 的 POS Invoice 中记录外卖订单的第三方平台订单号和平台标识  
**以便于** 能够追溯外卖订单来源，支持对账和数据分析

### AC 验收标准（初稿）

1. **WHEN** 创建 POS Invoice 时传入 `takeout_order_no` 和 `takeout_provider` **THEN** 系统 **SHALL** 将这些值保存到 ERPNext 的 `custom_takeout_order_no` 和 `custom_takeout_provider` 字段
2. **IF** 未传入 `takeout_order_no` 或 `takeout_provider` **THEN** 系统 **SHALL** 正常处理，不影响现有功能（向后兼容）
3. **WHEN** 查询 POS Invoice 时 **THEN** 系统 **SHALL** 返回包含 `custom_takeout_order_no` 和 `custom_takeout_provider` 的完整数据
4. **WHEN** Grab 外卖订单支付完成同步到 ERPNext 时 **THEN** 系统 **SHALL** 自动填充 `custom_takeout_order_no` 为 Grab 订单号，`custom_takeout_provider` 为 "grab"

### 技术实现要点

1. **ERPNext 自定义字段迁移文件**
   - 文件路径: `ttpos-bmp/app/ttpos-erp/manifest/erp-migrate/v2.12/01_custom_field/`
   - 文件1: `01_pos_invoice_takeout_order_no.json`
   - 文件2: `02_pos_invoice_takeout_provider.json`
   - 参考格式: `01_custom_payment_id.json`

2. **Protobuf 定义更新**
   - 文件: `ttpos-bmp/app/ttpos-erp/manifest/protobuf/selling/selling.proto`
   - 在 `SavePosInvoiceReq` 中增加：
     ```protobuf
     optional string takeout_order_no = 17;    // 外卖订单号，可选
     optional string takeout_provider = 18;    // 外卖平台提供商，可选
     ```

3. **DTO 结构更新**
   - 文件: `ttpos-bmp/app/ttpos-erp/internal/model/dto/erp/selling.go`
   - 在 `POSInvoice` 结构体中增加：
     ```go
     CustomTakeoutOrderNo   string `json:"custom_takeout_order_no,omitempty"`   // 外卖订单号
     CustomTakeoutProvider  string `json:"custom_takeout_provider,omitempty"`    // 外卖平台提供商
     ```

4. **业务逻辑更新**
   - 文件: `ttpos-bmp/app/ttpos-erp/internal/logic/selling/selling.go`
   - 在 `buildPosInvoice` 方法中增加字段赋值逻辑
