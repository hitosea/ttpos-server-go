## 🎯 背景和动机

### 问题描述

Barrio 客户反馈需要每个菜备注不同内容，但是手动输入太花费时间，影响点餐效率。

**当前痛点**：
- 收银员/点餐助手在点餐时需要为每个菜品手动输入备注内容
- 重复输入相同备注内容（如"不要香菜"、"少辣"、"打包"等）效率低下
- 手动输入容易出错，影响订单准确性
- 高峰期点餐时，手动输入备注会延长点餐时间，影响顾客体验

### 业务价值

**解决这个问题能带来什么业务价值？**

- ✅ **提升点餐效率**：通过预设选项快速选择备注，减少手动输入时间
- ✅ **提高订单准确性**：预设选项避免输入错误，减少因备注错误导致的客诉
- ✅ **改善用户体验**：缩短点餐时间，减少顾客等待
- ✅ **提升高峰期处理能力**：快速选择备注，提高单位时间内的订单处理量
- ✅ **统一备注管理**：商户可以统一管理常用备注选项，便于标准化服务

## 💡 解决方案概述

### 方案描述

参考整单备注的预设选项功能，为单品备注添加预设选项管理功能。商户管理员可以在商家管理端设置常用单品备注选项（支持多语言），收银员、点餐助手、H5/平板用户在点餐时可以从预设选项快速选择，也可以手动输入自定义备注。

**核心思路**：
1. 在商家管理端新增"单品备注预设选项"管理功能（类似整单备注设置）
2. 支持预设选项的增删改查，支持多语言
3. 各终端（收银机/点餐助手/H5/平板）在添加单品备注时，显示预设选项列表供快速选择
4. 保留手动输入功能，支持选择预设选项 + 手动补充

### 核心功能点

1. **商家管理端 - 单品备注预设选项管理**
   - 新增预设选项（支持多语言：中文、泰语、英语等）
   - 编辑预设选项
   - 删除预设选项
   - 查看预设选项列表
   - 限制预设选项数量（建议不超过 100 个，与整单备注保持一致）

2. **各终端 - 单品备注选择界面**
   - 显示预设选项列表（支持多语言显示）
   - 支持单选或多选预设选项
   - 支持手动输入自定义备注
   - 支持预设选项 + 手动输入组合

3. **数据存储与展示**
   - 订单商品备注字段存储选择的预设选项和自定义内容
   - 小票打印时正确显示备注内容
   - 订单详情中正确显示备注内容

## 📊 初步评估

### 技术复杂度

- [ ] **低**：纯 UI 调整，无业务逻辑变更
- [x] **中**：需要前后端联调，基础业务逻辑
- [ ] **高**：涉及架构调整、第三方集成、复杂算法

**说明**：
- 后端需要新增单品备注预设选项的数据模型和 CRUD 接口
- 前端需要新增商家管理端的设置页面
- 各终端需要调整备注选择界面，支持预设选项选择
- 可以参考整单备注的实现，技术复杂度中等

### 工作量预估

[粗略估算，具体 SP 在技术方案评审时确定]

- **预计天数**: 5-7 天
- **预估 SP**: 5 SP（待技术评审确认）

**分解**：
- 后端 API 开发：2 天
- 商家管理端 UI：1.5 天
- 各终端 UI 调整：2 天
- 测试与联调：1-1.5 天

### 风险识别

**潜在风险**：
1. **多语言支持**：预设选项需要支持多语言，需要确保各终端正确显示对应语言
2. **数据迁移**：如果已有历史订单使用了手动输入的备注，需要考虑兼容性
3. **备注显示格式**：预设选项 + 手动输入的组合显示格式需要统一
4. **性能影响**：预设选项列表可能较长，需要优化加载性能

**缓解措施**：
1. **多语言处理**：参考整单备注的多语言实现，使用相同的多语言字段结构
2. **兼容性处理**：保留手动输入功能，历史数据无需迁移，新功能向后兼容
3. **格式规范**：制定统一的备注显示格式规范（如：预设选项用分隔符分隔，手动输入追加）
4. **性能优化**：预设选项列表使用缓存，限制数量上限（100 个）

## 📝 附录

### User Story（初稿）

**作为** 收银员/点餐助手  
**我想** 在点餐时为菜品快速选择预设的备注选项  
**以便于** 提高点餐效率，减少手动输入时间，避免输入错误

**作为** 商户管理员  
**我想** 在商家管理端设置常用单品备注预设选项  
**以便于** 统一管理常用备注，标准化服务流程

**作为** 顾客（H5/平板点餐）  
**我想** 在点餐时快速选择菜品备注选项  
**以便于** 快速完成点餐，减少等待时间

### AC 验收标准（初稿）

1. **WHEN** 商户管理员在商家管理端新增单品备注预设选项 **THEN** 系统 **SHALL** 保存预设选项（支持多语言），并限制总数不超过 100 个

2. **WHEN** 收银员/点餐助手在点餐时添加单品备注 **THEN** 系统 **SHALL** 显示预设选项列表供快速选择，同时支持手动输入自定义备注

3. **WHEN** 用户选择预设选项并手动输入补充内容 **THEN** 系统 **SHALL** 正确保存和显示组合后的备注内容

4. **IF** 订单商品已添加备注（预设选项或手动输入） **THEN** 系统 **SHALL** 在小票打印和订单详情中正确显示备注内容

5. **WHEN** 商户管理员删除预设选项 **THEN** 系统 **SHALL** 不影响已使用该预设选项的历史订单，但新订单不再显示该选项
