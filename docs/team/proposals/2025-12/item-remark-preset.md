## 🎯 背景和动机

### 问题描述

客户反馈需要每个菜备注不同内容，但是手动输入太花费时间，影响点餐效率和用户体验。

**当前痛点**：
- 收银员/点餐员需要为每个菜品手动输入备注内容
- 重复输入相同或类似的备注内容，效率低下
- 在高峰期容易出错，影响服务速度
- 顾客等待时间增加，影响用餐体验

### 业务价值

- 提升点餐效率，减少重复输入时间
- 降低操作错误率，提高服务质量
- 缩短顾客等待时间，提升满意度
- 支持快速选择常用备注，提升用户体验

### 目标用户

- [x] 收银员
- [ ] 商户管理员
- [ ] 厨房人员
- [ ] 顾客
- [x] 其他: 点餐助手操作员

## 💡 解决方案概述

### 方案描述

允许商户管理员预先设置常用备注内容选项，在点餐时（收银机/点餐助手/H5/平板）为菜品添加备注时，可以直接从预设选项中选择，无需手动输入。支持为不同菜品设置不同的备注选项，提高操作效率。

### 核心功能点

1. **备注预设管理**：商户管理员可以在后台设置常用备注内容选项
2. **菜品关联备注**：支持为不同菜品配置专属的备注选项列表
3. **快速选择备注**：点餐时显示预设备注选项，支持快速选择
4. **自定义备注**：保留手动输入功能，支持自定义备注内容

- **预估 SP**: 5（待技术评审确认）

### 风险识别

**潜在风险**：
1. 备注选项过多时，选择界面可能过于复杂
2. 不同终端（H5/平板）的交互方式需要统一设计
3. 历史订单备注数据的兼容性处理

**缓解措施**：
1. 限制每个菜品的备注选项数量（建议 5-10 个）
2. 统一设计备注选择组件，适配不同终端
3. 保持向后兼容，支持查看历史自定义备注

## 📝 附录

### User Story（初稿）

**作为** 收银员/点餐员  
**我想** 从预设的备注选项中选择菜品备注  
**以便于** 快速完成点餐，减少重复输入时间

**作为** 商户管理员  
**我想** 为不同菜品设置常用备注选项  
**以便于** 提高点餐效率，统一服务标准

### AC 验收标准（初稿）

1. **WHEN** 商户管理员在后台设置备注选项 **THEN** 系统 **SHALL** 保存并关联到指定菜品
2. **WHEN** 收银员/点餐员为菜品添加备注 **THEN** 系统 **SHALL** 显示该菜品的预设备注选项
3. **WHEN** 用户选择预设备注 **THEN** 系统 **SHALL** 自动填充备注内容
4. **IF** 用户需要自定义备注 **THEN** 系统 **SHALL** 支持手动输入
5. **WHEN** 订单提交时 **THEN** 系统 **SHALL** 保存备注内容（预设或自定义）
