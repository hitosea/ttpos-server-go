## 🎯 背景和动机

### 问题描述

当前叫号系统（QDS）的配置项较为有限，商户无法灵活自定义叫号系统的显示内容和行为设置。商户希望能够：

1. **个性化展示**：自定义叫号系统的名称和背景图片，提升品牌识别度
2. **超时管理**：设置叫号超时限制，避免长时间占用叫号资源
3. **语音控制**：灵活控制是否启用语音叫号功能
4. **叫号内容定制**：自定义叫号时的提示内容
5. **叫号次数控制**：设置每个号码的叫号次数上限

**示例**：
> 商户希望在叫号屏幕上显示自己的品牌名称和品牌背景图，同时希望设置超时时间为 10 分钟，启用语音叫号，并自定义叫号内容为"请 A001 号顾客到 1 号窗口"，每个号码最多叫号 3 次。

## 💡 解决方案概述

### 方案描述

在新管理端（Go Main 模块）新增叫号系统配置管理功能，允许商户管理员设置以下配置项：

1. **叫号系统名称**：自定义显示在叫号屏幕上的系统名称
2. **背景图片**：上传并设置叫号屏幕的背景图片
3. **超时限制**：设置叫号超时时间（单位：分钟）
4. **语音叫号**：启用/关闭语音叫号功能
5. **叫号内容**：自定义叫号时的提示内容模板
6. **叫号次数**：设置每个号码的最大叫号次数

配置保存后，QDS 端（排号叫号端）将读取这些配置并应用到叫号展示中。

### 核心功能点

1. **叫号系统名称设置**：支持文本输入，限制长度，实时预览
2. **背景图片上传**：支持图片上传（JPG/PNG），图片大小限制，支持预览和删除
3. **超时限制设置**：数字输入框，单位分钟，设置范围限制（如 1-60 分钟）
4. **语音叫号开关**：开关组件，支持启用/关闭
5. **叫号内容模板**：文本输入框，支持变量占位符（如 {number}、{window}）
6. **叫号次数设置**：数字输入框，设置范围限制（如 1-10 次）

### 风险识别

**潜在风险**：
1. **图片存储**：需要考虑图片存储方案（OSS/本地），图片大小限制
2. **配置兼容性**：现有 QDS 端需要适配读取新配置项，可能存在兼容性问题
3. **默认值处理**：需要为各配置项设置合理的默认值

**缓解措施**：
1. 复用现有的图片上传服务（参考 `main/app/service/upload_file.go`）
2. 配置读取采用向后兼容的方式，缺失配置项使用默认值
3. 参考现有设置模块的实现方式（如 `main/app/service/setting/`）

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在新管理端设置叫号系统的名称、背景图片、超时限制、语音叫号开关、叫号内容和叫号次数  
**以便于** 个性化展示品牌形象，优化叫号流程，提升顾客体验

### AC 验收标准（初稿）

1. **WHEN** 商户管理员进入叫号系统配置页面 **THEN** 系统 **SHALL** 显示当前配置项（名称、背景图片、超时限制、语音叫号开关、叫号内容、叫号次数）

2. **WHEN** 商户管理员修改叫号系统名称并保存 **THEN** 系统 **SHALL** 保存配置并在 QDS 端显示新的名称

3. **WHEN** 商户管理员上传背景图片并保存 **THEN** 系统 **SHALL** 保存图片并在 QDS 端显示新的背景

4. **WHEN** 商户管理员设置超时限制为 X 分钟并保存 **THEN** 系统 **SHALL** 保存配置并在叫号超时 X 分钟后自动处理

5. **WHEN** 商户管理员关闭语音叫号开关并保存 **THEN** 系统 **SHALL** 保存配置并在 QDS 端禁用语音叫号

6. **WHEN** 商户管理员设置叫号内容模板并保存 **THEN** 系统 **SHALL** 保存配置并在叫号时使用该模板

7. **WHEN** 商户管理员设置叫号次数为 N 次并保存 **THEN** 系统 **SHALL** 保存配置并在达到 N 次后停止叫号

8. **IF** 商户管理员未设置某个配置项 **THEN** 系统 **SHALL** 使用默认值
