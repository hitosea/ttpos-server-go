## 🎯 背景和动机

### 问题描述

当前收银结账单打印联数只能按照打印机硬件设置的联数进行打印，无法灵活配置。实际业务场景中：

- **第一份给客户**：作为消费凭证，客户需要保留
- **第二份商家留存**：作为内部记录，用于后续核对

但不同商户对打印联数的需求不同，有些商户只需要打印一份给客户，有些需要多份用于不同用途。目前系统无法满足这种灵活的打印联数配置需求。

### 业务价值

- 提升商户打印配置的灵活性，满足不同业务场景需求
- 减少不必要的纸张浪费（当商户只需要1份时）
- 提高商户对系统的满意度
- 支持商户内部管理需求（多联打印用于不同部门）

## 💡 解决方案概述

### 方案描述

在新管理端的"工作台-餐厅管理"中增加"打印设置"功能模块，允许商户管理员自定义收银结账单的打印联数。配置后立即生效，结账单按照设置的打印联数进行打印。

### 核心功能点

1. **角色权限管理**
   - 在"餐厅设置"下增加"打印设置"权限
   - 角色默认勾选该权限

2. **打印设置配置**
   - 工作台-餐厅管理增加"打印设置"入口
   - 支持"票据类型打印联数设置"开关（默认关闭）
   - 关闭时按照打印机硬件联数打印
   - 开启后可设置自定义结账单打印联数
   - 输入范围：0-10的整数（0表示不打印）

3. **打印规则**
   - 配置后立即生效
   - 多语言打印出的结账单订单完全一致
   - 收银打印设置-结账单打印联数优先级高于打印设置-打印机打印联数
   - 补打结账单（打印小票）按照收银打印设置中结账单打印联数规则打印

### 风险识别

**潜在风险**：
1. 打印联数配置与打印机硬件联数不匹配可能导致打印异常
2. 多语言打印时联数配置的一致性保证
3. 补打功能需要兼容新的打印联数规则

**缓解措施**：
1. 在配置时进行合理性校验，提示用户打印机硬件联数
2. 确保多语言打印使用相同的打印联数配置
3. 补打功能复用相同的打印联数计算逻辑

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在打印设置中自定义收银结账单的打印联数  
**以便于** 满足不同业务场景的需求（客户凭证、商家留存等）

### AC 验收标准（初稿）

1. **WHEN** 商户管理员开启"票据类型打印联数设置" **THEN** 系统 **SHALL** 显示结账单打印联数配置项
2. **IF** 商户管理员设置结账单打印联数为 N（0-10） **THEN** 系统 **SHALL** 在结账时打印 N 份结账单
3. **IF** 商户管理员关闭"票据类型打印联数设置" **THEN** 系统 **SHALL** 按照打印机硬件联数打印
4. **WHEN** 商户管理员补打结账单 **THEN** 系统 **SHALL** 按照配置的打印联数打印
5. **WHEN** 多语言打印结账单 **THEN** 系统 **SHALL** 打印出的订单内容完全一致
6. **IF** 收银打印设置中配置了结账单打印联数 **THEN** 系统 **SHALL** 优先使用该配置，而非打印机硬件联数
