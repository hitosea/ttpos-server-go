## 🎯 背景和动机

### 问题描述

根据商家端"商品管理"页面的"批量操作"功能(如截图所示),商家需要能够批量将TTPOS系统中的商品推送/创建到外卖平台(Grab、LINE MAN等)。目前系统已支持从外卖平台导入商品到TTPOS,但缺少反向的批量创建功能。

具体业务场景:
- 商家在TTPOS中维护了大量商品数据
- 商家需要将这些商品批量同步到Grab、LINE MAN等外卖平台
- 商家需要批量上架、下架或删除外卖平台上的商品
- 避免逐个商品手动操作,提升运营效率

当前痛点:
- 只能单个商品推送到外卖平台,效率低下
- 缺少批量操作接口,无法支持前端的批量操作UI
- 商家在更新大量商品时需要花费大量时间

### 业务价值

- **提升运营效率**: 批量操作可减少90%以上的重复操作时间
- **降低操作成本**: 商家可一次性完成数百个商品的平台同步
- **提高数据一致性**: 批量操作能确保商品数据同步的及时性和准确性
- **增强平台竞争力**: 支持主流外卖平台(Grab、LINE MAN)的批量管理

## 💡 解决方案概述

### 方案描述

在商家端外卖管理模块中,新增批量操作接口,支持商家批量将TTPOS商品推送到外卖平台。该功能包含4个核心操作:

1. **批量创建**: 将选中的TTPOS商品批量推送到外卖平台(Grab/LINE MAN)
2. **批量上架**: 将选中的商品批量在外卖平台上架(设置为可售)
3. **批量下架**: 将选中的商品批量在外卖平台下架(设置为不可售)
4. **批量删除**: 将选中的商品批量从外卖平台删除

技术实现方面:
- 复用现有的外卖平台API集成代码
- 实现异步批量处理机制,避免阻塞主线程
- 提供进度查询接口,让商家了解批量操作的执行状态
- 记录操作日志,便于问题追踪和审计

### 核心功能点

1. **批量创建接口**: 支持批量将TTPOS商品推送到Grab/LINE MAN平台
2. **批量上架接口**: 支持批量上架外卖平台商品
3. **批量下架接口**: 支持批量下架外卖平台商品
4. **批量删除接口**: 支持批量删除外卖平台商品
5. **异步任务处理**: 批量操作异步执行,避免请求超时
6. **进度查询**: 提供任务进度查询接口
7. **失败重试**: 对失败的商品自动重试或标记失败原因
8. **操作日志**: 记录批量操作的详细日志

**工作量拆解**:
- 批量创建接口实现: 1-2 天
- 批量上架/下架/删除接口实现: 1 天
- 异步任务和进度查询: 1 天
- 测试和文档: 1 天

### 风险识别

**潜在风险**:
1. **外卖平台API限流**: Grab、LINE MAN可能对API调用频率有限制
2. **批量操作超时**: 批量处理大量商品可能导致请求超时
3. **部分失败处理**: 批量操作中部分商品成功、部分失败的处理逻辑
4. **数据一致性**: TTPOS与外卖平台数据同步的一致性问题
5. **平台API差异**: 不同外卖平台API规范不统一

**缓解措施**:
1. **限流控制**: 实现请求限流机制,控制调用频率(如每秒不超过10个请求)
2. **异步处理**: 采用异步任务队列,避免请求超时
3. **失败重试**: 对失败的商品自动重试3次,记录失败原因
4. **状态同步**: 操作成功后同步更新TTPOS的商品状态
5. **平台适配**: 为每个平台实现独立的适配器,统一接口规范

## 📝 附录

### User Story(初稿)

**作为** 商户管理员  
**我想** 批量将TTPOS商品推送到外卖平台(Grab、LINE MAN)  
**以便于** 快速完成大量商品的平台同步,避免逐个操作

### AC 验收标准(初稿)

1. **WHEN** 选择多个商品点击"批量创建Grab" **THEN** 系统 **SHALL** 将选中商品批量推送到Grab平台
2. **WHEN** 批量操作执行中 **THEN** 系统 **SHALL** 显示操作进度(如"已处理 50/100")
3. **IF** 部分商品推送失败 **THEN** 系统 **SHALL** 标记失败商品并显示失败原因
4. **WHEN** 批量操作完成 **THEN** 系统 **SHALL** 显示成功和失败的商品数量统计
5. **WHEN** 点击"批量上架Grab" **THEN** 系统 **SHALL** 将选中商品在Grab平台上架
6. **WHEN** 点击"批量下架LINE MAN" **THEN** 系统 **SHALL** 将选中商品在LINE MAN平台下架
7. **WHEN** 点击"批量删除Grab" **THEN** 系统 **SHALL** 从Grab平台删除选中商品
