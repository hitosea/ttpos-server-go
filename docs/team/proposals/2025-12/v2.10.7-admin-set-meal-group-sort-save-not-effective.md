## 🎯 背景和动机

### 问题描述

新管理端中，套餐分组排序功能保存后未生效，用户调整了套餐分组的排序顺序，但保存后排序没有按照预期更新。

**示例**：
> 商户管理员在新管理端调整套餐分组的显示顺序，点击保存后，页面刷新或重新进入时，排序又恢复到原来的顺序，导致排序设置无法生效。

[解决这个问题能带来什么业务价值？]

- 确保套餐分组排序功能正常工作

- 避免因功能异常导致的用户投诉
- 保证新管理端功能的完整性和可靠性

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 调整套餐分组的显示顺序并保存  
**以便于** 按照我的业务需求展示套餐分组，提升管理效率

### AC 验收标准（初稿）

1. **WHEN** 商户管理员调整套餐分组排序并点击保存 **THEN** 系统 **SHALL** 保存排序设置并持久化
2. **IF** 商户管理员保存排序后刷新页面或重新进入 **THEN** 系统 **SHALL** 按照保存的排序顺序显示套餐分组
3. **WHEN** 排序保存成功 **THEN** 系统 **SHALL** 给出明确的成功提示
