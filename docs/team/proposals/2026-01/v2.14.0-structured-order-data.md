## 🎯 背景和动机

### 问题描述

当前 `GetOrderInfoResp` 只返回 `raw_data` 字段（原始 JSON 数据），包含来自不同外卖平台（Grab、Lineman 等）的原始订单格式。前端或其他调用方需要：

1. **理解各平台的原始数据格式差异**（Grab 使用驼峰命名、Lineman 使用不同字段名）
2. **自行解析和转换**不同平台的数据结构
3. **处理字段映射关系**（如 Grab 的 `orderID` vs Lineman 的 `orderId`）

这导致：
- **重复劳动**：每个调用方都需要实现相同的数据转换逻辑
- **容错性差**：平台数据格式变更时，需要修改多处代码
- **开发效率低**：前端/其他服务需要维护复杂的转换逻辑

### 业务价值

**解决这个问题能带来的价值**：

1. **提升开发效率**：前端直接使用统一格式的数据，无需关心平台差异
2. **降低维护成本**：数据转换逻辑集中在 `takeout_converter.go`，平台变更时只需修改一处
3. **提高系统可扩展性**：新增外卖平台时，只需扩展 converter，不影响现有调用方
4. **增强接口语义**：同时返回原始数据（`raw_data`）和标准化数据（`order_data`），满足不同场景需求

## 💡 解决方案概述

### 方案描述

在 `GetOrderInfoResp` 消息中新增 `order_data` 字段（string 类型），该字段存储通过 `takeout_converter.go` 转换后的统一订单数据（`TakeoutOrder` JSON 格式）。

**实现逻辑**：
1. 保留现有 `raw_data` 字段（存储原始平台数据）
2. 新增 `order_data` 字段（存储转换后的 `TakeoutOrder` JSON）
3. 在返回订单信息时，调用 `takeout_converter.go` 的转换方法，将 `raw_data` 转换为 `TakeoutOrder` 结构
4. 将 `TakeoutOrder` 序列化为 JSON 字符串，填充到 `order_data` 字段

**数据流向**：
```
原始平台数据 (Grab/Lineman)
  ↓
存储到 raw_data (JSON)
  ↓
takeout_converter.go 转换
  ↓
TakeoutOrder 统一模型
  ↓
序列化为 JSON
  ↓
填充到 order_data 字段
```

### 核心功能点

1. **Protobuf 定义扩展**：在 `order.proto` 的 `GetOrderInfoResp` 中增加 `order_data` 字段
2. **数据转换集成**：在 `GetOrderInfo` 接口实现中调用 `takeout_converter.go` 进行数据转换
3. **JSON 序列化**：将转换后的 `TakeoutOrder` 结构序列化为 JSON 字符串
4. **向后兼容**：保留 `raw_data` 字段，确保现有调用方不受影响

### 风险识别

**潜在风险**：
1. **转换性能影响**：每次查询订单都需要执行数据转换，可能增加响应时间
2. **JSON 序列化开销**：`TakeoutOrder` 结构较大，序列化为 JSON 字符串有一定性能开销
3. **字段冗余**：同时返回 `raw_data` 和 `order_data`，增加响应体大小

**缓解措施**：
1. **性能监控**：在测试环境评估转换和序列化的耗时，确保在可接受范围（< 50ms）
2. **按需返回**：如果性能影响较大，可以考虑增加参数控制是否返回 `order_data`（默认返回）
3. **缓存优化**：对于频繁查询的订单，可以考虑缓存转换后的结果（后期优化）

## 📝 附录

### User Story（初稿）

**作为** 前端开发者  
**我想** 接收统一格式的外卖订单数据  
**以便于** 快速展示订单信息，无需关心不同平台的数据格式差异

**作为** 后端开发者  
**我想** 集中管理数据转换逻辑  
**以便于** 降低维护成本，提高系统可扩展性

### AC 验收标准（初稿）

1. **WHEN** 调用 `GetOrderInfo` 接口 **THEN** 响应中 **SHALL** 包含 `order_data` 字段
2. **IF** `raw_data` 为 Grab 订单 **THEN** `order_data` **SHALL** 包含转换后的 `TakeoutOrder` JSON（Grab 格式映射）
3. **IF** `raw_data` 为 Lineman 订单 **THEN** `order_data` **SHALL** 包含转换后的 `TakeoutOrder` JSON（Lineman 格式映射）
4. **WHEN** 转换失败 **THEN** `order_data` **SHALL** 为空字符串，并记录错误日志
5. **WHEN** 对比 `raw_data` 和 `order_data` **THEN** 核心字段（订单号、商品、价格等）**SHALL** 一致

### 数据示例

**Grab raw_data 示例**：
```json
{
  "orderID": "1234567890",
  "shortOrderNumber": "GRAB-001",
  "merchantID": "merchant-123",
  "paymentType": "CASHLESS"

```

**转换后的 order_data 示例**：
```json

  "paymentType": "CASHLESS",
  "items": [...],
  "price": {...}
}
```

### 技术实现参考

**Protobuf 定义修改**：
```protobuf
message GetOrderInfoResp {
  string shop_uuid = 1;       // TTPOS店铺UUID
  string order_status = 2;    // 订单状态
  string order_type = 3;      // 订单类型
  string raw_data = 4;        // 原始JSON数据
  string provider_name = 5;   // 渠道名称: grab, foodpanda, lineman
  string order_data = 6;      // 转换后的统一订单数据（TakeoutOrder JSON）
}
```

**转换逻辑伪代码**：
```go
// 获取订单信息
func GetOrderInfo(ctx context.Context, req *GetOrderInfoReq) (*GetOrderInfoResp, error) {
    // 1. 查询订单
    order, err := dao.GetOrder(ctx, req.OrderId)
    if err != nil {
        return nil, err
    }
    
    // 2. 获取 raw_data
    rawData := order.RawData
    
    // 3. 转换为 TakeoutOrder
    var takeoutOrder message.TakeoutOrder
    switch order.ProviderName {
    case "grab":
        takeoutOrder, err = converter.ConvertGrabToTakeoutOrder(rawData)
    case "lineman":
        takeoutOrder, err = converter.ConvertLinemanToTakeoutOrder(rawData)
    default:
        return nil, fmt.Errorf("unsupported provider: %s", order.ProviderName)
    }
    
    if err != nil {
        // 转换失败，记录日志但不影响返回 raw_data
        log.Error("failed to convert order data", "error", err)
    }
    
    // 4. 序列化为 JSON
    orderDataJSON, _ := json.Marshal(takeoutOrder)
    
    // 5. 返回
    return &GetOrderInfoResp{
        ShopUuid:     order.ShopUuid,
        OrderStatus:  order.Status,
        OrderType:    order.Type,
        RawData:      rawData,
        ProviderName: order.ProviderName,
        OrderData:    string(orderDataJSON), // 新增字段
    }, nil
}
```
