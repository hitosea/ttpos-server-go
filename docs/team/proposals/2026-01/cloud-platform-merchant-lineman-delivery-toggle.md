## 🎯 背景和动机

### 问题描述

当前云平台的商家管理模块中，新增或编辑商家时无法配置 LINE MAN 外卖功能的开启/关闭状态，导致商家无法灵活控制是否启用 LINE MAN 外卖服务。随着 LINE MAN 在泰国市场的普及，商家需要能够独立控制 LINE MAN 外卖服务的启用状态。

### 业务价值

- 为商家提供 LINE MAN 外卖服务的灵活控制能力
- 支持商家根据业务需求动态开启/关闭 LINE MAN 外卖
- 提升云平台商家管理的完整性和便捷性
- 增强系统的第三方外卖平台集成管理能力
- 支持多外卖平台并存，商家可独立控制各平台的启用状态

## 💡 解决方案概述

### 方案描述

在云平台的商家管理模块中，新增/编辑商家时增加 LINE MAN 外卖功能的开启/关闭开关配置项。商家可以通过该配置控制是否启用 LINE MAN 外卖服务，配置后系统会根据该状态控制 LINE MAN 外卖相关的业务逻辑。

该功能与现有的 Grab 外卖开关功能类似，两者相互独立，商家可以同时开启或分别控制。

### 核心功能点

1. 在商家新增/编辑页面新增 LINE MAN 外卖开启/关闭开关
2. 支持商家配置 LINE MAN 外卖服务的启用状态
3. 配置状态影响 LINE MAN 外卖相关的业务逻辑（如订单接收、菜单同步等）
4. 与 Grab 外卖开关相互独立，互不影响

4. 参考 Grab 外卖开关的实现方式，保持一致性

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在云平台新增/编辑商家时配置 LINE MAN 外卖的开启/关闭状态  
**以便于** 根据业务需求灵活控制是否启用 LINE MAN 外卖服务

### AC 验收标准（初稿）

1. **WHEN** 在云平台新增商家时 **THEN** 系统 **SHALL** 提供 LINE MAN 外卖开启/关闭开关配置项
2. **WHEN** 在云平台编辑商家时 **THEN** 系统 **SHALL** 显示当前 LINE MAN 外卖配置状态并允许修改
3. **IF** LINE MAN 外卖已开启 **THEN** 系统 **SHALL** 正常接收和处理 LINE MAN 外卖订单
4. **IF** LINE MAN 外卖已关闭 **THEN** 系统 **SHALL** 停止接收 LINE MAN 外卖订单
5. **IF** LINE MAN 外卖已关闭 **THEN** 新管理端 **SHALL** 不显示 LINE MAN 外卖相关权限和功能
6. **LINE MAN 外卖开关** 与 **Grab 外卖开关** **SHALL** 相互独立，互不影响
