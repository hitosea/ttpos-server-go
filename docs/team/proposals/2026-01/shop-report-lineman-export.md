## 🎯 背景和动机

### 问题描述

当前旧商家后台的统计报表导出功能中缺少 LINEMAN 平台的订单数据。商户在导出报表时无法获取 LINEMAN 渠道的销售数据，导致报表数据不完整，影响业务分析和决策。

### 业务价值

- **数据完整性**：报表包含所有外卖平台数据，便于统一管理
- **决策支持**：完整数据有助于运营分析和业务决策
- **工作效率**：减少手动汇总数据的时间，提升工作效率

### 目标用户

- [x] 店长
- [x] 商户管理员
- [x] 运营人员
- [x] 财务人员

---

## 💡 解决方案概述

### 方案描述

在现有统计报表导出功能中增加 LINEMAN 数据列，保持报表格式不变，新增 LINEMAN 平台的订单统计数据，使报表能够完整展示包括 Grab、LINEMAN 等外卖平台的全部数据。

### 核心功能点

1. 统计报表导出增加 LINEMAN 订单数量列
2. 统计报表导出增加 LINEMAN 销售金额列
3. 汇总数据包含 LINEMAN 平台数据

### 影响范围

**涉及终端**：
- [x] Shop 商家管理端（旧版）

**涉及模块**：
- [x] API 接口（报表导出接口）
- [x] 业务逻辑（数据统计逻辑）
