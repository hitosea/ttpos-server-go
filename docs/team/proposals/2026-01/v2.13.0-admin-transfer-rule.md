## 🎯 背景和动机

### 问题描述

当前系统中，各门店在发起调拨时只有固定的调拨类型选项，缺乏总店级别的规则控制。这导致：

1. 无法根据业务策略灵活控制门店的调拨权限
2. 所有门店都能发起调入和调出，无法针对特定门店进行限制
3. 缺少总店对各门店调拨行为的统一管理能力

**实际业务场景**：
> 总部希望能够统一管理各门店的调拨权限，例如某些门店只允许发起调入，某些门店只允许发起调出，从而更好地控制库存流向和调拨流程。

### 业务价值

- **加强库存管控**：总部可以根据实际业务需求，灵活配置各门店的调拨权限
- **规范调拨流程**：通过规则限制，避免不合理的调拨操作
- **提升管理效率**：统一在总店进行配置，无需逐店沟通和管理
- **支持业务策略**：配合不同的库存管理策略（如中心仓模式、对等调拨模式等）

## 💡 解决方案概述

### 方案描述

在新管理端的业务设置中增加"调拨规则"功能，允许总店管理员配置各门店的调拨发起类型：

1. **调入**：门店可以发起调入单，从其他门店调入物料
2. **调出**：门店可以发起调出单，向其他门店调出物料

总店管理员可以通过勾选的方式控制各门店允许的调拨类型。为保证业务连续性，至少需要保留一种调拨类型（当只剩一个选项时，该选项置灰不可取消）。

配置生效后，各门店在发起调拨时，只能看到并选择被允许的调拨类型。

### 核心功能点

1. **总店配置界面**：新增"调拨规则"设置页面，可配置各门店的调拨发起类型
2. **规则验证**：至少保留一个调拨类型，最后一个选项置灰不可取消
3. **权限控制**：门店发起调拨时，根据规则过滤可选的调拨类型
4. **规则生效**：配置后立即生效，门店端实时更新可用的调拨类型选项

### 风险识别

**潜在风险**：
1. **数据迁移风险**：现有调拨单可能需要兼容新的规则逻辑
2. **用户体验风险**：门店可能不理解为什么调拨类型突然变少
3. **业务连续性风险**：规则配置错误可能导致门店无法正常调拨

**缓解措施**：
1. **数据兼容**：规则表设计支持默认值，未配置门店默认允许所有类型
2. **操作提示**：在门店端给出明确的提示信息，说明调拨类型受总店规则限制
3. **规则验证**：前端强制校验至少保留一个类型，后端双重校验

## 📝 附录

### User Story（初稿）

**作为** 总店管理员  
**我想** 配置各门店允许的调拨发起类型（调入/调出）  
**以便于** 根据业务策略统一管理门店的调拨权限，规范库存流向

### AC 验收标准（初稿）

#### AC1：核心功能验证

**Given** 总店管理员进入"业务设置 - 调拨规则"页面

**When** 勾选某门店的"调入"选项

**Then** 该门店在发起调拨时可以看到并选择"调入"类型

**When** 勾选某门店的"调出"选项

**Then** 该门店在发起调拨时可以看到并选择"调出"类型

**When** 取消勾选某个选项

**Then** 该门店在发起调拨时不再显示该类型选项

#### AC2：边界场景处理

**Given** 某门店只剩最后一个调拨类型选项（调入或调出）

**When** 管理员尝试取消该选项

**Then** 该选项应置灰，无法取消，并提示"至少保留一个调拨类型"

#### AC3：交互验证

**Given** 总店配置了门店A只允许调入

**When** 门店A管理员进入调拨单发起页面

**Then** 只显示"调入"选项，"调出"选项不可见

**Given** 未配置调拨规则的门店

**When** 门店管理员进入调拨单发起页面

**Then** 默认显示"调入"和"调出"两个选项（保持兼容性）
