## 🎯 背景和动机

### 问题描述

当前盘点单审核流程存在以下痛点：

1. **驳回后无法修改重提**：单据被驳回后，发起人只能重新创建新单据，无法基于原单据修改后重新提交，导致重复录入工作量大
2. **审核缺少批注功能**：审核人在通过或驳回时无法添加说明信息，发起人不清楚驳回原因或需要关注的要点，沟通效率低下

### 业务价值

- **效率提升**：减少重复录入工作，加快审批流程周转
- **沟通改善**：批注信息有助于审核双方理解问题，减少来回沟通成本
- **合规需求**：审批操作留痕，满足内控审计要求，便于追溯审批历史

### 目标用户

- [x] 店长/商户管理员（单据发起人、门店审核人）
- [x] 运营人员（库存管理相关）
- [x] 总部审批人员（终审人员）

## 💡 解决方案概述

### 方案描述

在盘点单审核流程中增加批注功能和重新提交机制。审核人在通过或驳回单据时可添加批注说明；单据被驳回后，发起人可在详情页点击"重新提交审核"按钮，系统自动加载原单据信息，支持修改后重新提交，同时完整记录所有操作历史。

### 核心功能点

1. **审核批注**：门店通过/驳回时增加批注输入框（非必填）
2. **重新提交审核**：驳回单据详情页显示"重新提交审核"按钮，保留原单据信息并支持修改
3. **批注历史页**：独立的批注内页，按时间倒序展示所有操作记录（操作类型、时间、批注信息）
4. **批注摘要展示**：单据详情页顶部显示最新批注摘要（最多8字符），点击进入批注内页
5. **操作留痕**：记录门店通过、门店驳回、重新提交等操作的时间和批注信息

## 📝 附录

### User Story（初稿）

**作为** 店长/商户管理员
**我想** 在盘点单被驳回后能够修改并重新提交，同时在审核时能添加批注说明
**以便于** 减少重复录入工作，提高审批沟通效率，并满足操作留痕的合规要求

### AC 验收标准（初稿）

1. **WHEN** 门店通过盘点申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"门店通过"、操作时间、通过批注信息
2. **WHEN** 门店驳回盘点申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"门店驳回"、操作时间、驳回批注信息
3. **WHEN** 用户重新提交被驳回的盘点申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"重新提交"、操作时间
4. **WHEN** 用户在批注内页查看操作记录 **THEN** 系统 **SHALL** 按时间倒序展示所有操作记录
5. **WHEN** 单据有多次驳回和重新提交操作 **THEN** 系统 **SHALL** 在批注内页中展示完整的操作时间线
