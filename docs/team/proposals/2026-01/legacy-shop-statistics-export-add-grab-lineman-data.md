## 🎯 背景和动机

### 问题描述

当前旧商家后台的统计报表导出功能中，销售统计和支付数据统计缺少 Grab 和 LINE MAN 平台的数据，导致商家无法完整查看所有渠道的销售和支付情况，影响数据分析和经营决策。

### 业务价值

- 提供完整的多渠道销售数据视图
- 支持商家全面分析各平台（包括 Grab 和 LINE MAN）的销售表现
- 提升数据导出功能的完整性和准确性
- 帮助商家更好地进行经营决策和渠道优化

## 💡 解决方案概述

### 方案描述

在旧商家后台的统计报表导出功能中，为销售统计（按天）和支付数据（按天）两个报表增加 Grab 和 LINE MAN 平台的数据支持。确保这两个平台的数据能够正确统计并显示在导出的报表中，且 Grab 和 LINE MAN 数据排列在最后。

### 核心功能点

1. **销售统计（按天）导出**：增加 Grab 数据/LINE MAN 数据的统计和导出
2. **支付数据（按天）导出**：增加 Grab 数据/LINE MAN 数据的统计和导出，注意：Grab 和 LINE MAN 排在最后

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在统计报表导出中查看包含 Grab 和 LINE MAN 平台的完整销售和支付数据  
**以便于** 全面分析各渠道的经营表现，做出更好的经营决策

### AC 验收标准（初稿）

1. **WHEN** 商户管理员导出销售统计（按天）报表 **THEN** 系统 **SHALL** 包含 Grab 和 LINE MAN 平台的销售数据
2. **WHEN** 商户管理员导出支付数据（按天）报表 **THEN** 系统 **SHALL** 包含 Grab 和 LINE MAN 平台的支付数据，且这两个平台的数据排列在最后
3. **IF** Grab 或 LINE MAN 平台有订单数据 **THEN** 系统 **SHALL** 正确统计并显示在导出的报表中
