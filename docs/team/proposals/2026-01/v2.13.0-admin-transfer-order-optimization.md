## 🎯 背景和动机

### 问题描述

当前调拨单管理界面缺少角色视角的区分，用户无法快速筛选与自己相关的调拨单，导致：
- 门店在查看调拨单时，需要逐个查看单据才能确认是调出、调入还是需要审核
- 无法快速定位到需要自己处理的调拨单（如待审核的单据）
- 不同角色的门店（调出方、调入方、审核方）查看需求不同，但界面统一展示，效率低下

### 业务价值

优化后将带来以下价值：
- **提升操作效率**：门店可以快速筛选出自己关注的调拨单类型
- **减少审核遗漏**：明确显示需要本店审核的单据，避免审核延误
- **改善用户体验**：以本店视角展示不同角色的单据，符合用户心智模型
- **降低培训成本**：界面更符合业务场景，减少用户学习成本

## 💡 解决方案概述

### 方案描述

在调拨单管理界面增加"我发出/我接收/我审核"三种类型筛选，以本店视角查看不同角色的调拨单：

1. **我发出**：显示本店作为调出方的调拨单，查看本店调出的单据状态
2. **我接收**：显示本店作为调入方的调拨单，查看本店调入的单据状态（默认选中）
3. **我审核**：显示当前需要本店审核的调拨单，包括各种审核场景

每种类型都有对应的状态筛选，方便用户快速定位目标单据。

### 核心功能点

1. **类型筛选器**：增加"我发出/我接收/我审核"三个筛选选项
   - 默认选中"我接收"
   - 支持取消选择，显示全部单据
   - 单选模式，同时只能选择一种类型

2. **我发出**视图
   - 显示本店作为调出方的调拨单
   - 状态筛选：全部、待提交、待审核、已驳回、待收货、已完成

3. **我接收**视图
   - 显示本店作为调入方的调拨单
   - 状态筛选：全部、待提交、待审核、已驳回、待收货、已完成

4. **我审核**视图
   - 显示当前需要本店审核的单据（当前审核节点 == 本店UUID）
   - 仅显示"待审核"状态
   - 包含四种审核场景：
     - 场景1：本店是调出方，审核流程进行到"发出方审核"节点
     - 场景2：本店是调入方，审核流程进行到"接收店审核"节点
     - 场景3：本店是调出方的上级门店，审核流程进行到"发出方上级门店审核"节点
     - 场景4：本店是调入方的上级门店，审核流程进行到"接收方上级门店审核"节点

## 📊 初步评估

### 技术复杂度

- [x] **中**：需要前后端联调，涉及审核流程判断逻辑

**技术难点**：
1. "我审核"视图需要判断当前审核节点是否为本店
2. 需要处理四种不同的审核场景
3. 需要确保审核节点判断逻辑与现有审核流程一致

### 工作量预估

[粗略估算，具体 SP 在技术方案评审时确定]

- **预计天数**: 3-5 天
- **预估 SP**: 5-8 SP（待技术评审确认）

**工作量分解**：
- 前端开发：筛选器组件 + 列表视图调整（2-3天）
- 后端开发：接口调整 + 审核节点判断逻辑（1-2天）
- 联调测试：场景覆盖测试（1天）

### 风险识别

**潜在风险**：
1. 审核节点判断逻辑可能与现有流程不一致，导致"我审核"视图数据不准确
2. 不同审核场景的判断条件复杂，可能遗漏边界情况
3. 性能问题：筛选逻辑可能影响列表查询性能

**缓解措施**：
1. 详细梳理现有审核流程，与产品确认所有审核场景
2. 编写完整的单元测试覆盖所有审核场景
3. 对查询逻辑进行性能测试，必要时增加数据库索引

## 📝 附录

### User Story（初稿）

**作为** 门店管理员  
**我想** 在调拨单管理界面按"我发出/我接收/我审核"三种视角查看单据  
**以便于** 快速定位需要我处理的调拨单，提高工作效率

### AC 验收标准（初稿）

**AC1: 类型筛选器功能**
- **GIVEN** 用户进入调拨单管理页面
- **WHEN** 页面加载完成
- **THEN** 系统默认选中"我接收"筛选器，显示本店作为调入方的调拨单

**AC2: 我发出视图**
- **GIVEN** 用户在调拨单管理页面
- **WHEN** 用户点击"我发出"筛选器
- **THEN** 系统显示本店作为调出方的所有调拨单
- **AND** 状态筛选器包含：全部、待提交、待审核、已驳回、待收货、已完成

**AC3: 我接收视图**
- **GIVEN** 用户在调拨单管理页面
- **WHEN** 用户点击"我接收"筛选器
- **THEN** 系统显示本店作为调入方的所有调拨单
- **AND** 状态筛选器包含：全部、待提交、待审核、已驳回、待收货、已完成

**AC4: 我审核视图**
- **GIVEN** 用户在调拨单管理页面
- **WHEN** 用户点击"我审核"筛选器
- **THEN** 系统显示当前需要本店审核的所有调拨单（当前审核节点 == 本店UUID）
- **AND** 仅显示"待审核"状态的单据
- **AND** 包含四种审核场景的单据：
  - 场景1：本店是调出方，审核流程进行到"发出方审核"节点
  - 场景2：本店是调入方，审核流程进行到"接收店审核"节点
  - 场景3：本店是调出方的上级门店，审核流程进行到"发出方上级门店审核"节点
  - 场景4：本店是调入方的上级门店，审核流程进行到"接收方上级门店审核"节点

**AC5: 取消选择功能**
- **GIVEN** 用户已选择某个筛选器（如"我接收"）
- **WHEN** 用户再次点击该筛选器
- **THEN** 系统取消选择，显示所有调拨单（全部单据）

**AC6: 边界场景处理**
- **GIVEN** 某个调拨单已通过审核进入下一节点
- **WHEN** 用户在"我审核"视图中查看
- **THEN** 该调拨单不再显示在列表中
- **AND** 系统提示"当前无待审核单据"（如列表为空）
