## 🎯 背景和动机

### 问题描述

当前报表功能无法灵活选择数据指标，且无法同时对比多个门店在不同日期的经营表现。用户需要：
- 快速对比各门店在不同日期的经营表现
- 了解每日和整体经营状况
- 导出报表进行进一步分析

**当前痛点**：
- 无法灵活选择要查看的数据指标（营业数据汇总/支付方式汇总/退款金额汇总）
- 无法同时多选门店和多选日期进行对比分析
- 缺乏每日各店数据和汇总数据的统一展示

### 业务价值

- ✅ **提升数据分析效率**：支持多指标、多门店、多日期灵活组合查询
- ✅ **快速对比分析**：同时查看各门店在不同日期的经营表现
- ✅ **数据导出能力**：支持导出报表进行进一步分析
- ✅ **权限精细化控制**：根据用户角色和权限范围展示对应门店数据

## 💡 解决方案概述

### 方案描述

在报表页面新增"门店汇总统计"功能，支持：
1. **数据指标选择**：可选择"营业数据汇总"、"支付方式汇总"、"退款金额汇总"三种指标
2. **门店多选**：根据用户权限范围列出可查看的门店，支持多选
3. **日期多选**：支持选择多个日期进行对比分析
4. **数据展示**：表格展示每天各店数据和汇总数据
5. **数据导出**：支持导出报表

**重要约束**：已经被数据管理的订单，不参与此模块的计算（需要过滤）。

### 核心功能点

1. **数据指标选择**
   - 下拉框支持选择：营业数据汇总、支付方式汇总、退款金额汇总
   - 选择后表格展示对应指标数据

2. **门店选择**
   - 列出用户拥有权限的门店（不可跨集团取值）
   - 总店/分店用户：可查看本店及下级门店
   - 子店用户：可查看子店汇总数据，若在多家子店可多选查看
   - 支持【全部门店】全选/取消全选
   - 全选状态下取消单个门店，自动取消【全部门店】勾选

3. **日期选择**
   - 支持多选日期
   - 默认显示今天

4. **数据展示**
   - 表格展示每天各店数据
   - 展示汇总数据
   - 支持数据导出

5. **权限控制**
   - 根据用户角色和权限范围展示对应门店
   - 不可跨集团取值

## 📊 交互流程说明

### 1. 页面初始化

- 进入门店汇总统计页面
- 默认展示"营业数据汇总"
- 门店默认为当前门店
- 时间范围默认为今天

### 2. 数据指标选择

- 点击数据指标下拉框
- 可选择：
  - 营业数据汇总
  - 支付方式汇总
  - 退款金额汇总
- 选择后下方表格展示对应指标数据

### 3. 门店选择

**权限规则**：
- 用户在总店/分店，并拥有"门店汇总统计"板块权限时，可选择查看本店及下级门店
- 用户在子店，并拥有"门店汇总统计"板块权限时，可查看子店汇总数据。若在多家子店，可多选查看
- 不可跨集团取值

**交互逻辑**：
- 点击【全部门店】，全选所有门店
- 再次点击【全部门店】，取消全选
- 在全选情况下取消某一门店的勾选，自动取消【全部门店】的勾选

### 4. 日期选择

- 支持多选日期
- 默认选择今天

### 5. 数据展示

- 表格展示每天各店数据
- 展示汇总数据
- 支持导出报表

### 风险识别

**潜在风险**：
1. 数据过滤逻辑复杂：需要准确过滤已被数据管理的订单
2. 权限控制复杂：需要根据用户角色和权限范围正确展示门店列表

**缓解措施**：
1. 明确数据管理订单的标识字段，确保过滤逻辑准确
2. 梳理权限模型，明确各角色的门店查看范围
3. 优化查询SQL，考虑使用索引和缓存策略

## 📝 附录

### User Story（初稿）

**作为** 商户管理员（总店/分店/子店）  
**我想** 在报表页面先选择要查看的数据指标（营业数据汇总/支付方式汇总/退款金额汇总），然后多选门店和多选日期，查看对应指标的每天各店数据和汇总数据  
**以便于** 快速对比各门店在不同日期的经营表现，了解每日和整体经营状况，并导出报表进行进一步分析

### AC 验收标准（初稿）

1. **WHEN** 用户进入门店汇总统计页面 **THEN** 系统 **SHALL** 默认展示"营业数据汇总"、当前门店、今天的数据
2. **WHEN** 用户选择数据指标 **THEN** 系统 **SHALL** 展示对应指标的表格数据
3. **WHEN** 用户在总店/分店选择门店 **THEN** 系统 **SHALL** 仅显示本店及下级门店（不可跨集团）
4. **WHEN** 用户在子店选择门店 **THEN** 系统 **SHALL** 仅显示该子店或用户有权限的多家子店
5. **WHEN** 用户点击【全部门店】 **THEN** 系统 **SHALL** 全选所有可查看门店
6. **WHEN** 用户在全选状态下取消单个门店 **THEN** 系统 **SHALL** 自动取消【全部门店】的勾选
7. **WHEN** 用户选择多个日期 **THEN** 系统 **SHALL** 展示每天各店数据和汇总数据
8. **WHEN** 数据中包含已被数据管理的订单 **THEN** 系统 **SHALL** 过滤这些订单，不参与计算
9. **WHEN** 用户点击导出 **THEN** 系统 **SHALL** 导出当前查询条件的报表数据
