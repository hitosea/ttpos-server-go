## 🎯 背景和动机

### 问题描述

当前 LINE MAN 外卖平台集成中，`lineman_token` 服务仅实现了基于 JWT 的 Partner Token 生成与验证功能，但缺少类似 Grab 平台的 OAuth Access Token 获取与缓存机制。

在实际业务场景中：
- 每次调用 LINE MAN API 时都需要携带有效的 Access Token
- 频繁向 LINE MAN 服务器请求 Token 会导致不必要的网络开销和延迟
- 缺少缓存机制会增加 LINE MAN 服务器的负担，可能触发频率限制
- Token 管理逻辑分散在各个业务模块中，维护成本高

**参考实现**：Grab 平台已有成熟的 `getAccessToken()` 方法，通过 Redis 缓存 + 双重检查锁机制实现了高效的 Token 管理。

### 业务价值

- **提升性能**：通过 Redis 缓存减少 90% 以上的 Token 请求次数
- **降低延迟**：缓存命中时响应时间从 100-300ms 降低到 1-5ms
- **提高稳定性**：避免频繁请求导致的限流风险
- **统一管理**：集中化 Token 管理，降低维护成本
- **架构一致性**：与 Grab 平台保持相同的实现模式，便于团队维护

## 💡 解决方案概述

### 方案描述

参考 Grab 平台的 `getAccessToken()` 实现，在 `lineman_token` 服务中新增 OAuth Access Token 获取与缓存功能：

1. **Token 获取流程**：
   - 首次请求时向 LINE MAN OAuth 服务器获取 Access Token
   - 将 Token 缓存到 Redis，设置合理的 TTL（Token 有效期 - 缓冲时间）
   - 后续请求优先从 Redis 读取缓存

2. **缓存策略**：
   - Redis Key 格式：`lineman:oauth:token:{client_id}`
   - TTL = Token 有效期 - 60 秒缓冲时间（避免边界情况）
   - 使用双重检查锁（Double-Check Lock）避免并发重复请求

3. **容错机制**：
   - Redis 缓存失败不影响业务，仅记录日志
   - Token 过期时自动重新获取
   - 支持手动刷新 Token

### 核心功能点

1. **GetAccessToken()** - 获取或刷新 Access Token（带 Redis 缓存）
2. **FetchTokenFromAPI()** - 从 LINE MAN OAuth 服务器获取新 Token
3. **GetAuthorizationHeader()** - 获取格式化的 Authorization 请求头
4. **RefreshToken()** - 手动刷新 Token（可选）

## 📝 附录

### User Story（初稿）

**作为** 外卖平台集成开发人员  
**我想** 在调用 LINE MAN API 时自动获取并缓存 Access Token  
**以便于** 减少网络请求次数，提升系统性能和稳定性

### AC 验收标准（初稿）

1. **WHEN** 首次调用 `GetAccessToken()` **THEN** 系统 **SHALL** 向 LINE MAN OAuth 服务器请求 Token 并缓存到 Redis
2. **WHEN** Token 已缓存且未过期 **THEN** 系统 **SHALL** 直接从 Redis 返回 Token，不发起网络请求
3. **WHEN** Token 已过期 **THEN** 系统 **SHALL** 自动重新获取新 Token 并更新缓存
4. **WHEN** Redis 不可用 **THEN** 系统 **SHALL** 降级到直接调用 API，不影响业务
5. **WHEN** 并发请求同时获取 Token **THEN** 系统 **SHALL** 使用双重检查锁避免重复请求
6. **WHEN** 调用 `GetAuthorizationHeader()` **THEN** 系统 **SHALL** 返回格式化的 `Bearer {token}` 字符串

### 技术实现要点

#### 1. Redis Key 设计

```go
const (
    RedisKeyTokenPrefix = "lineman:oauth:token:"
    TokenExpireBuffer   = 60 // 秒，缓冲时间
)

// Redis Key: lineman:oauth:token:{client_id}
redisKey := RedisKeyTokenPrefix + conf.ClientID
```

#### 2. 核心方法签名

```go
// GetAccessToken 获取或刷新 Access Token (使用 Redis 缓存)
func (s *sLinemanToken) GetAccessToken(ctx context.Context) (string, error)

// FetchTokenFromAPI 从 LINE MAN OAuth 服务器获取新 Token
func (s *sLinemanToken) FetchTokenFromAPI(ctx context.Context) (token string, expiresIn int, err error)

// GetAuthorizationHeader 获取 Authorization 请求头
func (s *sLinemanToken) GetAuthorizationHeader(ctx context.Context) (string, error)
```

#### 3. 缓存流程伪代码

```go
func (s *sLinemanToken) GetAccessToken(ctx context.Context) (string, error) {
    // 1. 尝试从 Redis 读取
    cachedToken, err := g.Redis().Get(ctx, redisKey)
    if err == nil && !cachedToken.IsEmpty() {
        return cachedToken.String(), nil
    }

    // 2. 获取锁，避免并发重复请求
    s.tokenLock.Lock()
    defer s.tokenLock.Unlock()

    // 3. Double check: 再次检查缓存
    cachedToken, err = g.Redis().Get(ctx, redisKey)
    if err == nil && !cachedToken.IsEmpty() {
        return cachedToken.String(), nil
    }

    // 4. 从 LINE MAN API 获取新 Token
    token, expiresIn, err := s.FetchTokenFromAPI(ctx)
    if err != nil {
        return "", err
    }

    // 5. 写入 Redis 缓存
    ttl := expiresIn - TokenExpireBuffer
    if ttl > 0 {
        g.Redis().SetEX(ctx, redisKey, token, int64(ttl))
    }

    return token, nil
}
```

#### 4. LINE MAN OAuth API 调用示例

```go
func (s *sLinemanToken) FetchTokenFromAPI(ctx context.Context) (string, int, error) {
    conf := s.MustConf()
    
    // 构造 OAuth Token 端点 URL
    tokenURL := strings.TrimRight(conf.Endpoint, "/") + "/oauth/token"
    
    // 构造 OAuth 请求
    reqBody := map[string]string{
        "grant_type":    "client_credentials",
        "client_id":     conf.ClientID,
        "client_secret": conf.ClientSecret,
        "scope":         "partner_api", // 根据 LINE MAN 文档调整
    }
    
    // 发送 HTTP POST 请求
    resp, err := g.Client().Post(ctx, tokenURL, reqBody)
    if err != nil {
        return "", 0, gerror.Wrap(err, "LINE MAN OAuth 请求失败")
    }
    
    // 解析响应
    var result struct {
        AccessToken string `json:"access_token"`
        ExpiresIn   int    `json:"expires_in"`
        TokenType   string `json:"token_type"`
    }
    if err := resp.ReadJSON(&result); err != nil {
        return "", 0, gerror.Wrap(err, "解析 OAuth 响应失败")
    }
    
    g.Log().Infof(ctx, "[LINE MAN] OAuth Token 获取成功, expires_in=%d", result.ExpiresIn)
    return result.AccessToken, result.ExpiresIn, nil
}
```
