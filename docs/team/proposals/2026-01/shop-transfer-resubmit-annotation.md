## 🎯 背景和动机

### 问题描述

当前调拨单审核流程存在以下痛点：

1. **驳回后无法修改重提**：单据被驳回后，发起人只能重新创建新单据，无法基于原单据修改后重新提交，导致重复录入工作量大
2. **审核缺少批注功能**：审核人在通过或驳回时无法添加说明信息，发起人不清楚驳回原因或需要关注的要点，沟通效率低下
3. **操作缺乏追溯**：调拨单涉及多方审核（门店、上级门店、发货/收货门店），缺少完整的操作历史记录

### 业务价值

- **效率提升**：被驳回后可快速修改重新提交，无需重新创建单据
- **操作留痕**：完整记录审核过程，满足内控审计要求，便于追溯审批历史
- **体验改善**：批注信息帮助发起人了解驳回原因，针对性修改

### 目标用户

- [x] 店长/商户管理员（单据发起人、门店审核人）
- [x] 上级门店审核人（多级审批）
- [x] 发货/收货门店（调入/调出确认）

## 💡 解决方案概述

### 方案描述

在调拨单审核流程中增加批注功能和重新提交机制。审核人在通过或驳回单据时可添加批注说明；单据被驳回后，发起人可在详情页点击"重新提交审核"按钮，系统自动加载原单据信息，支持修改后重新提交，同时完整记录所有操作历史。

### 核心功能点

1. **重新提交审核**：驳回单据详情页显示"重新提交审核"按钮，保留原单据信息（商品列表、数量、备注等）并支持编辑修改
2. **审核批注**：门店通过/驳回、上级门店通过/驳回、发货门店通过/驳回、收货门店通过/驳回时增加批注输入框（非必填）
3. **批注历史页**：独立的批注内页，按时间倒序展示所有操作记录（操作类型、时间、批注信息，暂时不记录操作人）
4. **批注摘要展示**：单据详情页顶部显示最新批注摘要（最多8字符），点击进入批注内页
5. **操作留痕**：记录所有审核节点的操作时间和批注信息

## 📝 附录

### User Story（初稿）

**作为** 店长/商户管理员
**我想** 在调拨单被驳回后能够修改并重新提交，同时在审核时能添加批注说明
**以便于** 减少重复录入工作，提高审批沟通效率，并满足操作留痕的合规要求

### AC 验收标准（初稿）

1. **WHEN** 单据被驳回 **THEN** 发起人在调拨单据详情页 **SHALL** 看到"重新提交审核"按钮
2. **WHEN** 发起人修改调拨单据内容并重新提交审核 **THEN** 系统 **SHALL** 验证必填项和业务规则
3. **WHEN** 验证通过 **THEN** 系统 **SHALL** 将单据状态变更为"待审核"，并记录操作历史
4. **WHEN** 门店通过调拨申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"门店通过"、操作时间、通过批注信息（暂时不记录操作人）
5. **WHEN** 门店驳回调拨申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"门店驳回"、操作时间、驳回批注信息（暂时不记录操作人）
6. **WHEN** 用户重新提交被驳回的调拨申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"重新提交"、操作时间（暂时不记录操作人）
7. **WHEN** 上级门店审核通过调拨申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"上级门店通过"、操作时间、通过批注信息（暂时不记录操作人）
8. **WHEN** 上级门店驳回调拨申请 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"上级门店驳回"、操作时间、驳回批注信息（暂时不记录操作人）
9. **WHEN** 发货门店通过调拨申请【调入】 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"发货门店通过"、操作时间、通过批注信息（暂时不记录操作人）
10. **WHEN** 发货门店驳回调拨申请【调入】 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"发货门店驳回"、操作时间、驳回批注信息（暂时不记录操作人）
11. **WHEN** 收货门店通过调拨申请【调出】 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"收货门店通过"、操作时间、通过批注信息（暂时不记录操作人）
12. **WHEN** 收货门店驳回调拨申请【调出】 **THEN** 系统 **SHALL** 在批注内页中记录：操作类型为"收货门店驳回"、操作时间、驳回批注信息（暂时不记录操作人）
13. **WHEN** 用户在批注内页查看操作记录 **THEN** 系统 **SHALL** 按时间倒序展示所有操作记录，每条记录包含操作类型、操作时间、批注信息（暂时不包含操作人）
14. **WHEN** 单据有多次驳回和重新提交操作 **THEN** 系统 **SHALL** 在批注内页中展示完整的操作时间线，清晰展示每次操作的时间节点和批注信息
