## 🎯 背景和动机

### 问题描述

当前新管理端缺少细粒度的角色权限管理功能，无法为不同岗位的员工分配不同的功能权限。这导致：

- 所有员工拥有相同的权限，存在安全风险
- 无法根据岗位职责灵活配置权限
- 权限管理不够精细化，难以满足不同商户的管理需求

### 业务价值

- 提升系统安全性，通过权限控制降低误操作风险
- 支持精细化权限管理，满足不同岗位的权限需求
- 提高管理效率，便于商户进行员工权限配置
- 符合企业级应用的权限管理标准

## 💡 解决方案概述

### 方案描述

在新管理端增加角色权限管理功能，支持创建角色、配置功能权限、关联员工等操作。通过角色-权限-员工的关联模型，实现灵活的权限管理。

### 核心功能点

1. **添加角色功能**

   - 角色名称：必填，1-50 字符
   - 功能权限：支持管理 APP、收银机、点餐助手等模块的权限配置
   - 管理 APP 默认勾选所有权限
   - 特殊权限规则：
     - 总部无品采收货权限
     - 散户无品牌采购、品牌收货、调拨单权限
     - 未对接 ERP 无进销存权限
     - 若关闭渠道营收统计，则首页：渠道营收统计无"更多"

2. **编辑角色功能**

   - 支持修改角色名称和功能权限
   - 支持关联员工（仅在编辑时可用）

3. **删除角色功能**

   - 关联员工时删除按钮置灰
   - 未关联时删除需确认提示："确定删除角色吗？"

4. **权限隐藏规则**
   - 商家后台隐藏管理 APP 权限（uuid=2856266502144000），仅平台管理端可见

5. **国际化支持**
   - 获取门店所有权限时，权限名称需根据请求头的语言返回相应语言的名称
   - 支持语言：中文（zh）、英文（en）等
   - 通过 Accept-Language 或自定义请求头识别语言

### 风险识别

**潜在风险**：

1. 权限规则复杂，需要处理多种业务场景（总部、ERP 对接、渠道营收统计等）
2. 权限变更可能影响现有用户的使用体验
3. 需要确保权限验证逻辑的准确性
4. 国际化翻译可能存在不完整或不准确的情况

**缓解措施**：

1. 详细梳理权限规则，建立权限配置矩阵
2. 提供权限预览功能，确保配置正确
3. 充分测试各种权限组合场景
4. 建立完整的多语言翻译表，确保所有权限名称都有对应的翻译

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 创建角色并配置功能权限  
**以便于** 为不同岗位的员工分配合适的权限，提升系统安全性和管理效率

### AC 验收标准（初稿）

1. **WHEN** 管理员点击"添加角色" **THEN** 系统 **SHALL** 显示角色创建表单，包含角色名称和功能权限配置
2. **IF** 角色名称为空或超过 50 字符 **THEN** 系统 **SHALL** 提示错误信息
3. **IF** 选择管理 APP 权限 **THEN** 系统 **SHALL** 默认勾选所有权限
4. **IF** 商家后台访问 **THEN** 系统 **SHALL** 隐藏管理 APP 权限选项（uuid=2856266502144000）
5. **IF** 总部商户 **THEN** 系统 **SHALL** 隐藏品采收货权限选项
6. **IF** 散户商户 **THEN** 系统 **SHALL** 隐藏品牌采购、品牌收货、调拨单权限选项
7. **IF** 未对接 ERP **THEN** 系统 **SHALL** 隐藏进销存权限选项
8. **IF** 关闭渠道营收统计 **THEN** 系统 **SHALL** 隐藏首页渠道营收统计的"更多"选项
9. **WHEN** 编辑角色时 **THEN** 系统 **SHALL** 显示关联员工功能
10. **IF** 角色已关联员工 **THEN** 系统 **SHALL** 置灰删除按钮
11. **IF** 角色未关联员工且点击删除 **THEN** 系统 **SHALL** 显示确认提示："确定删除角色吗？"
12. **WHEN** 请求头包含 Accept-Language 为 "en" **THEN** 系统 **SHALL** 返回英文权限名称
13. **WHEN** 请求头包含 Accept-Language 为 "zh" 或未指定 **THEN** 系统 **SHALL** 返回中文权限名称
