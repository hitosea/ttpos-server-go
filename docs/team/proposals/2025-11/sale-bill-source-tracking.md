## 🎯 背景和动机

### 问题描述

当前系统在创建订单时，虽然 `SaleBill` 表已有 `source` 字段用于记录订单来源，但在实际创建订单的业务逻辑中并未正确设置该字段值。这导致无法准确追踪订单来自哪个客户端，影响后续的数据分析和业务决策。

**现状**：
- `SaleBill` 表已存在 `source` 字段（类型：`int(10)`，默认值：0）
- 字段注释已定义：`0-默认值、1-收银机、2-点餐助手、3-平板、4-H5、5-会员端`
- 但创建订单时，`source` 字段始终为默认值 0，未根据实际请求来源设置

**痛点**：
- 无法区分订单来自收银机、点餐助手、平板还是 H5
- 影响订单来源统计和分析
- 无法针对不同来源的订单进行差异化处理

### 业务价值

解决这个问题能带来以下业务价值：

- **数据统计准确性**：准确记录订单来源，支持按来源维度进行数据分析
- **业务决策支持**：了解各客户端的订单占比，优化产品策略
- **问题排查能力**：当订单出现问题时，可快速定位来源客户端
- **运营分析**：支持按来源分析订单转化率、客单价等关键指标

## 💡 解决方案概述

### 方案描述

在创建订单的业务逻辑中，根据请求上下文（`ctx.GetSource()`）自动设置 `SaleBill` 表的 `source` 字段值。系统已具备获取请求来源的能力（通过 JWT token 中的 source 信息），只需在创建 `SaleBill` 时映射并设置正确的值。

**实现要点**：
1. 定义 Source 常量映射：将 JWT Source 值映射到 `source` 字段值（0-4）
2. 在创建 `SaleBill` 的所有入口处，根据 `ctx.GetSource()` 设置 `source` 字段
3. 确保向后兼容：对于无法识别来源的请求，使用默认值 0

### 核心功能点

1. **定义 Source 映射常量**
   - 在 `constant` 包中定义 Source 到 source 字段值的映射关系
   - 支持：收银机(1)、点餐助手(2)、平板(3)、H5(4)、会员端(5)、默认值(0)

2. **修改订单创建逻辑**
   - 在 `CreateInstantOrder`（即时订单）中设置 source
   - 在 `CreateDeskOrder`（桌台订单）中设置 source
   - 在 `createMemberOrder`（会员端订单）中设置 source
   - 在其他创建 SaleBill 的地方统一设置 source

3. **确保数据一致性**
   - 所有创建 SaleBill 的代码路径都要设置 source
   - 添加单元测试验证 source 字段设置正确性

### 风险识别

**潜在风险**：
1. **遗漏创建入口**：可能存在其他创建 SaleBill 的代码路径未设置 source
2. **历史数据**：已有订单的 source 字段为 0，无法追溯真实来源
3. **JWT Source 值不完整**：某些客户端可能未正确设置 JWT 中的 source 信息

**缓解措施**：
1. **代码审查**：全面搜索 `CreateSaleBill` 调用，确保所有路径都设置 source
2. **历史数据**：接受历史数据无法追溯的现实，从新版本开始记录
3. **默认值处理**：对于无法识别的来源，使用默认值 0，并在日志中记录警告

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在订单数据中看到订单来自哪个客户端  
**以便于** 分析各客户端的使用情况和订单转化率

### AC 验收标准（初稿）

1. **WHEN** 通过收银机创建订单 **THEN** 系统 **SHALL** 在 SaleBill 表的 source 字段记录为 1
2. **WHEN** 通过点餐助手创建订单 **THEN** 系统 **SHALL** 在 SaleBill 表的 source 字段记录为 2
3. **WHEN** 通过平板创建订单 **THEN** 系统 **SHALL** 在 SaleBill 表的 source 字段记录为 3
4. **WHEN** 通过 H5 创建订单 **THEN** 系统 **SHALL** 在 SaleBill 表的 source 字段记录为 4
5. **WHEN** 通过会员端创建订单 **THEN** 系统 **SHALL** 在 SaleBill 表的 source 字段记录为 5
6. **WHEN** 无法识别来源时 **THEN** 系统 **SHALL** 在 SaleBill 表的 source 字段记录为 0（默认值）
7. **WHEN** 查询历史订单时 **THEN** 系统 **SHALL** 正确返回 source 字段值
