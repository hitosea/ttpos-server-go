## 🎯 背景和动机

### 问题描述

普通员工在进行折扣/退款操作时需要输入门店经理/店长的权限密码进行验证，但当前系统中员工账号缺少权限密码字段，无法实现权限密码验证功能。

**用户故事**：

> 作为门店经理/店长，我想为员工账号设置权限密码，以便于在敏感操作（如折扣、退款）时进行权限验证，控制普通员工的操作权限。

### 业务价值

- ✅ 支持权限密码验证：为敏感操作验证功能提供基础数据支持
- ✅ 增强权限控制：通过权限密码区分普通员工和管理人员
- ✅ 降低财务风险：敏感操作需要授权员工密码验证
- ✅ 符合餐饮行业管理规范：重要操作需要上级授权

### 目标用户

- [x] 商户管理员（店长/门店经理）
- [x] 普通员工（收银员、服务员）

---

## 💡 解决方案概述

### 方案描述

在员工账号管理中新增"权限密码"字段，支持为每个员工设置权限密码。权限密码默认值为 666888，密码必须为 4-8 位数字，系统在设置密码时进行校验。**本功能需要在两个终端实现：1) 新管理端（Go 项目的 shop 目录：`main/app/api/v1/shop/`）；2) (旧)商家后台（PHP 项目的 admin/shop 目录：`admin/app/shop/`）。** **注意：本提案仅包含员工账号的权限密码设置功能，密码验证逻辑将在其他任务中实现。**

### 核心功能点

1. **权限密码字段**

   - 在员工账号中新增权限密码字段
   - 权限密码默认值：666888
   - 密码格式要求：4-8 位数字
   - 设置保存后，密码信息存储到数据库（加密存储）

2. **密码设置和编辑**

   - 支持在添加/编辑员工时设置权限密码
   - 支持修改权限密码
   - 密码输入时进行格式校验

3. **密码格式验证**
   - 密码必须为 4-8 位数字
   - 系统在设置密码时进行校验
   - 若输入不符合规则，提示"密码必须为 4 - 8 位数字"

**说明**：本功能仅负责员工账号的权限密码设置和保存，不包含密码验证逻辑的实现。

### 影响范围

**涉及终端**：

- [x] **新管理端**：Go 项目的 shop 目录（`main/app/api/v1/shop/`）- 员工账号管理页面
- [x] **(旧)商家后台**：PHP 项目的 admin/shop 目录（`admin/app/shop/`）- 员工账号管理页面

**涉及模块**：

- [x] UI 组件（新管理端和商家后台的员工管理页面）
- [x] API 接口（Go：员工信息保存接口；PHP：员工信息保存接口）
- [x] 数据模型（员工表，存储权限密码字段）

**不涉及**：

- ❌ 密码验证逻辑（将在其他任务中实现）
- ❌ 敏感操作验证流程（将在其他任务中实现）

3. 统一两个终端的实现方式，确保数据格式一致

## 📝 附录

### User Story（初稿）

**作为** 门店经理/店长  
**我想** 为员工账号设置权限密码  
**以便于** 在敏感操作（如折扣、退款）时进行权限验证，控制普通员工的操作权限

### AC 验收标准（初稿）

1. **WHEN** 添加/编辑员工账号 **THEN** 系统 **SHALL** 显示权限密码输入框，默认值为 666888
2. **WHEN** 设置权限密码 **THEN** 系统 **SHALL** 验证密码格式（4-8 位数字）
3. **IF** 密码不符合格式（不是 4-8 位数字） **THEN** 系统 **SHALL** 提示"密码必须为 4 - 8 位数字"
4. **WHEN** 保存员工信息 **THEN** 系统 **SHALL** 将权限密码加密后存储到数据库
5. **WHEN** 重新打开员工编辑页面 **THEN** 系统 **SHALL** 不显示密码明文（显示为空或占位符）

**注意**：密码验证逻辑的验收标准将在其他任务中定义。
