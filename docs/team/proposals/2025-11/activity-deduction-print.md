# 提案: 满减营销功能（打印相关）

**编号**: DooTask #37078  
**提案人**: weifashi  
**提交日期**: 2025-11-25  
**状态**: 待评审

---

## 背景和动机

### 问题描述

当前打印模板中缺少"活动抵扣"字段的显示，无法在结账单、预结账单和发票中体现满减营销活动的抵扣金额。这会导致顾客和商家在查看打印单据时，无法清晰了解优惠明细，影响用户体验和财务对账的准确性。

### 业务价值

- 提升打印单据的信息完整性，让顾客清楚看到满减优惠金额
- 便于商家财务对账，准确追踪营销活动的实际抵扣情况
- 统一优惠信息展示规范，与优惠券抵扣保持一致的显示逻辑

---

## 解决方案概述

在打印模板中新增"活动抵扣"字段显示，通过现有的 `activity_amount` 字段获取数据，放置在"优惠券抵扣"下一行。

### 核心功能点

1. **自定义模板扩展**

   - 在自定义模板的应付信息区域中增加"活动抵扣"字段
   - 支持自定义字段的显示/隐藏控制

2. **标准模板更新**

   - 商家后台的结账单模板增加"活动抵扣"显示
   - 商家后台的预结账单所有模板增加"活动抵扣"显示
   - 发票模版 2（Invoice Template 2）增加"活动抵扣"显示

3. **多语言支持**
   - 中文简体：活动抵扣
   - 中文繁体：活動抵扣
   - English: Activity Deduction
   - ภาษาไทย: หักลดจากกิจกรรม
   - Türkçe: Etkinlik indir
   - 日本語：活動控除
   - 한국어：활동 공제
   - Svenska: Aktivitetavdrag
   - မြန်မာဘာသာ：လှုပ်ရှားမှုလျှော့

## 技术方案

### 数据源

- **字段**: `activity_amount`（现有字段）
- **类型**: decimal(10,2)
- **说明**: 满减营销活动的抵扣金额

### 实现范围

#### 1. 自定义打印模板

**核心文件**:

- **配置文件**: `main/app/printer/pkg/template/statement_order_config.json`
  - 在 `"block_id": "amount_due_information"` 区块的 `data_rows` 中新增"活动抵扣"字段配置
  - 添加多语言支持的 `block_label`
- **渲染逻辑**: `main/app/printer/template/statement_order_img_custom.go`
  - 在 `GetPrintContent()` 方法中添加 `activity_amount` 字段的读取和渲染
  - 确保在"优惠券抵扣"之后渲染

**实现细节**:

1. 在 JSON 配置中添加新的 data_row 项：

   ```json
   {
     "block_id": "activity_deduction",
     "block_type": "label_value",
     "block_label": {
       "zh": "活动抵扣",
       "zhtw": "活動抵扣",
       "en": "Activity Deduction",
       "th": "หักลดจากกิจกรรม",
       "tr": "Etkinlik indir",
       "ja": "活動控除",
       "ko": "활동 공제",
       "sv": "Aktivitetavdrag",
       "my": "လှုပ်ရှားမှုလျှော့"
     },
     "block_value": "{{activity_amount}}"
   }
   ```

2. 在 Go 渲染代码中处理 `{{activity_amount}}` 占位符

#### 2. 标准打印模板

**影响的模板类型**:

- 结账单（Check）
- 预结账单（Pre-Check）
- 发票模版 2（Invoice Template 2）

**更新位置**:

- 在"优惠券抵扣"字段下方增加一行
- 格式: `活动抵扣: ￥{activity_amount}`

**相关文件**:

- `main/app/printer/template/statement_order_img.go` (标准模板渲染)

### 显示逻辑

```text
商品总价:     ￥69.98
会员优惠:     ￥3
会员积分抵扣: ￥15
优惠券抵扣:   ￥3
活动抵扣:     ￥50.00    ← 新增
减免金额:     ￥3
应付金额:     ￥0.00
```

### 实现步骤

1. **更新自定义模板配置（JSON）**

   - 打开 `main/app/printer/pkg/template/statement_order_config.json`
   - 定位到 `"block_id": "amount_due_information"` 的 `data_rows` 数组
   - 在优惠券抵扣项之后，插入新的 `activity_deduction` 配置块
   - 添加完整的多语言 `block_label` 定义

2. **更新自定义模板渲染逻辑（Go）**

   - 修改 `main/app/printer/template/statement_order_img_custom.go`
   - 在 `GetPrintContent()` 方法中：
     - 从 `saleBill` 或相关模型读取 `activity_amount` 字段
     - 使用 `decimal` 类型处理金额格式化（保留两位小数）
     - 将 `{{activity_amount}}` 占位符替换为实际金额值
   - 确保字段在"优惠券抵扣"之后渲染

3. **更新标准模板渲染逻辑**

   - 修改 `main/app/printer/template/statement_order_img.go`
   - 在结账单、预结账单、发票模板的渲染代码中添加"活动抵扣"行
   - 保持与自定义模板一致的显示格式和位置

4. **验证数据源**

   - 确认 `activity_amount` 字段在 `SaleBill` 或相关模型中已存在
   - 检查字段类型是否为 `decimal.Decimal` 或 `float64`
   - 确保数据库字段有正确的默认值（0.00）

5. **多语言支持验证**

   - 确认 JSON 配置中包含所有 9 种语言的翻译
   - 测试不同语言环境下的打印效果

6. **测试验证**
   - 创建满减营销活动并下单
   - 在不同语言环境下打印结账单/预结账单/发票
   - 验证金额格式、位置、多语言显示均正确
   - 检查 `activity_amount = 0` 时的显示效果
