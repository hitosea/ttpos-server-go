## 🎯 背景和动机

### 问题描述

当前套餐商品管理功能需要增强，以支持更灵活的分组和选择机制。现有系统在套餐商品配置上存在以下限制：

- 套餐商品分组类型单一，无法支持可选/必选的分组配置
- 商品价格设置不够灵活，无法支持加价模式
- 缺少对可选数量、必选数量等关键参数的控制
- 商品数量默认值需要优化

### 业务价值

通过增强套餐商品管理功能，可以：

- 提升套餐配置的灵活性，满足不同业务场景需求
- 支持更复杂的套餐组合规则（可选/必选、数量控制）
- 优化商品价格设置方式（支持加价模式）
- 改善商户使用体验，降低配置复杂度

## 💡 解决方案概述

### 方案描述

在旧管理端的商品管理模块中，针对套餐商品增加以下功能：

1. **分组类型配置**：为套餐商品增加"分组类型"字段，支持"固定"和"可选"两种类型
2. **可选数量控制**：当选择"可选"类型时，支持设置本组可选数量（默认 1）
3. **必选/默认设置**：支持设置必选和默认选项
4. **价格模式优化**：将商品价格改为加价模式，加价默认 0
5. **数量默认值**：商品数量默认设置为 1
6. **数据校验**：必选数量不可大于可选数量

### 核心功能点

1. **分组类型管理**

   - 增加"分组类型"字段，默认值为"固定"
   - 支持"固定"和"可选"两种类型

2. **可选分组配置**

   - 当选择"可选"类型时，显示"本组可选数量"字段（默认 1）
   - 显示"必选"和"默认"选项配置

3. **价格模式调整**

   - 将商品价格字段改为"加价"字段
   - 加价默认值为 0

4. **数量默认值**

   - 商品数量默认设置为 1

5. **数据校验**
   - 当必选数量大于可选数量时，提示错误："必选不可大于可选数量"

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在商品管理中配置套餐的分组类型、可选数量、必选/默认选项，以及商品的加价和数量  
**以便于** 创建更灵活、更符合业务需求的套餐商品，提升套餐配置的灵活性和用户体验

### AC 验收标准（初稿）

#### AC1：分组类型配置

**Given** 套餐商品  
**When** 进入商品编辑页面  
**Then** 显示"分组类型"字段，默认值为"固定"

#### AC2：可选类型配置

**Given** 套餐商品选择"可选"类型  
**When** 选择"可选"类型  
**Then** 显示"本组可选数量"字段（默认 1），显示"必选"和"默认"选项

#### AC3：价格模式调整

**Given** 套餐商品  
**When** 编辑商品价格  
**Then** 价格字段改为"加价"字段，默认值为 0

#### AC4：数量默认值

**Given** 套餐商品  
**When** 添加商品到套餐  
**Then** 商品数量默认设置为 1

#### AC5：数据校验

**Given** 必选数量大于可选数量  
**When** 保存配置  
**Then** 提示错误："必选不可大于可选数量"

#### AC6：数量计算说明

**Given** 套餐包含多个商品（如商品 A 数量 2，商品 B 数量 1）  
**When** 设置可选数量为 3  
**Then** 系统正确计算总数量（A*2*2 + B\*1 = 5 杯饮料）
