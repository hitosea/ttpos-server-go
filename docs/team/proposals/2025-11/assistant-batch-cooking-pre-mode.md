## 🎯 背景和动机

### 问题描述

当前点餐助手端在分批送厨场景下，仅支持后置关联模式（下单后再选择分批类型）。在实际使用中，店员在选购商品时就需要明确该商品属于哪个分批类型（如主食、饮料、小食等），以便于后厨按类型分批制作。

**痛点**：

- 店员需要在选购商品时就明确分批类型，但系统只能在送厨时选择
- 无法在加购阶段就关联分批类型，导致操作流程不够直观
- 下单后需要手动选择分批类型，增加操作步骤

### 业务价值

- **提升操作效率**：在选购商品时即可选择分批类型，减少后续操作步骤
- **优化用户体验**：操作流程更符合实际业务场景，降低学习成本
- **提高准确性**：前置选择分批类型，减少送厨时的误操作
- **统一体验**：与收银端前置模式保持一致，降低多终端切换的学习成本

## 💡 解决方案概述

### 方案描述

在点餐助手端实现分批送厨的前置关联模式，允许店员在选购商品时就选择并关联分批类型。系统支持两种模式：

- **前置模式**：选购商品时选择分批类型并关联
- **后置模式**：下单后再选择分批类型（现有功能）

当商户开启前置模式时，助手端将：

1. 在开桌完成时显示分批类型选择弹窗
2. 支持切换分批类型，左上角显示当前选中的类型
3. 选购商品时自动关联当前选中的分批类型
4. 下单后自动按优先级送厨（每次送优先级最高的类型）.点记一次下单就送厨一批最高优先级的分批类型商品

### 核心功能点

1. **分批模式配置**：在 `/assistant/base` 接口中返回当前商户的分批送厨模式（前置/后置）
2. **分批类型列表**：新增接口获取分批类型列表，按 sort 排序（优先级高的在前）
3. **商品加购增强**：加购接口支持 `batch_tag_uuid` 参数，前置模式时自动关联分批类型
4. **智能送厨**：下单后自动按分批类型优先级送厨，每次送优先级最高的类型

### 风险识别

**潜在风险**：

1. 前置模式与后置模式的切换可能影响现有业务流程
2. 商品签名计算逻辑需要确保相同商品不同分批类型能正确分开显示
3. 自动送厨逻辑需要确保按优先级正确执行

**缓解措施**：

1. 通过业务设置控制模式切换，默认使用后置模式，保证向后兼容
2. 在商品签名计算中加入 `batch_tag_uuid` 参数，确保正确区分
3. 充分测试自动送厨逻辑，确保按 sort 排序正确送厨

## 📝 附录

### User Story（初稿）

**作为** 点餐助手端用户（店员）  
**我想** 在选购商品时就选择并关联分批类型  
**以便于** 下单后系统能自动按类型分批送厨，减少操作步骤，提高效率

### AC 验收标准（初稿）

#### AC1: 分批模式配置

- **GIVEN** 商户开启分批送厨前置模式
- **WHEN** 调用 `/assistant/base` 接口
- **THEN** 接口返回 `batch_cooking_mode` 字段，值为 `pre`（前置模式）

#### AC2: 分批类型列表

- **GIVEN** 商户已配置分批类型
- **WHEN** 调用新增的分批类型列表接口
- **THEN** 返回分批类型列表，按 `sort` 字段排序（优先级高的在前）

#### AC3: 商品加购关联分批类型

- **GIVEN** 商户开启前置模式，已选择分批类型 A
- **WHEN** 调用加购接口，传入 `batch_tag_uuid` 参数
- **THEN** 商品成功加购并关联分批类型 A
- **AND** 相同商品不同分批类型在购物车中分开显示

#### AC4: 自动送厨逻辑

- **GIVEN** 已下单，存在多个分批类型的预送厨商品
- **WHEN** 点击下单按钮
- **THEN** 所有分批送厨商品变为预送厨状态
- **AND** 自动送厨优先级最高的分批类型商品
- **AND** 每次点击下单都送优先级最高的类型，直到没有可送厨商品

#### AC5: 商品签名计算

- **GIVEN** 前置模式，相同商品但不同分批类型
- **WHEN** 计算商品签名
- **THEN** 签名中包含 `batch_tag_uuid`，确保分开显示

### 技术实现要点

根据任务内容，助手端功能改动包括：

1. **接口增强**：

   - `/assistant/base` 接口增加 `batch_cooking_mode` 字段
   - 新增 `/assistant/batch_tag/list` 接口获取分批类型列表

2. **加购接口修改**：

   - `/assistant/order/cart/product/add` 接口增加 `batch_tag_uuid` 参数
   - 前置模式时，计算商品签名需包含 `batch_tag_uuid`
   - 相同签名商品合并，不同签名分开显示

3. **下单送厨逻辑**：
   - 点击下单后，所有分批送厨商品变为预送厨状态
   - 分析所有预送厨商品，找出优先级最高的分批类型
   - 自动送厨该类型商品
   - 每次点击下单都重复此过程，直到没有可送厨商品
