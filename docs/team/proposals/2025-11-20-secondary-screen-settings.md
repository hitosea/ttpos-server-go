## 🎯 背景和动机

### 问题描述

华莱士希望可以在收银机副屏上显示广告和订单信息，提升顾客体验和营销效果。

**当前状态**：收银端设置中已有未点餐时的副屏轮播图设置（`cashier.carousel`），但缺少轮播间隔设置，以及点餐时的设置（展示模式和轮播间隔）。

**当前痛点**：
- 缺少未点餐时轮播间隔设置
- 缺少点餐时的展示模式配置（轮播内容、点餐内容、点餐内容+轮播内容）
- 缺少点餐时轮播间隔设置
- 无法根据点餐状态动态切换副屏内容

### 业务价值

- **提升营销效果**：通过副屏轮播广告，增加品牌曝光和促销信息展示
- **改善用户体验**：顾客可以在副屏查看订单详情，减少询问
- **增强品牌形象**：专业的双屏收银体验，提升门店形象
- **提高运营效率**：统一管理副屏内容，支持多门店配置

### 目标用户

- [x] 商户管理员（配置副屏设置）
- [x] 收银员（使用副屏展示）
- [x] 顾客（查看副屏内容）

---

## 💡 解决方案概述

### 方案描述

**本次提案仅限接口开发，前端不需要处理。**

在现有收银机设置基础上扩展，添加：
1. 未点餐时的轮播间隔设置
2. 点餐时的展示模式设置（轮播内容、点餐内容、点餐内容+轮播内容）
3. 点餐时的轮播间隔设置

收银端通过接口获取副屏配置，前端根据当前点餐状态动态展示相应内容。

**说明**：轮播内容最多支持15个图片或视频。

### 核心功能点

1. **管理端收银机设置扩展**
   - 未点餐时轮播间隔设置（10-120秒，默认10秒）
   - 点餐时展示模式配置（轮播内容、点餐内容、点餐内容+轮播内容）
   - 点餐时轮播间隔设置（10-120秒，默认10秒）
   - 轮播内容数量限制：最多15个图片或视频

2. **收银端副屏应用接口**
   - 扩展现有收银机设置接口，返回新增字段（前端根据点餐状态自行处理显示逻辑）

3. **数据存储**
   - 扩展现有 `setting` 表的 `cashier` 配置 JSON 字段
   - 不需要创建新表

### 影响范围

**涉及终端**：
- [x] POS 收银端（应用副屏设置）
- [x] Shop 商家管理端（配置副屏设置）

**涉及模块**：
- [x] API 接口（扩展现有收银机设置接口）
- [x] 数据模型（扩展现有收银机设置 JSON 字段）
- [x] 文件存储（轮播内容上传，已存在）

**说明**：
- 收银端仅提供配置获取接口，不处理点餐状态判断和内容切换逻辑
- 前端根据获取的配置和当前点餐状态自行决定显示内容

- [x] **中**：需要前后端联调，基础业务逻辑

### 工作量预估

[粗略估算，具体 SP 在技术方案评审时确定]

- **预计天数**: 3.5-4.5 天
- **预估 SP**: 5 SP（符合要求）

**分解**：
- 数据结构扩展：0.5 天（扩展 CashierResp 和设置 JSON）
- 管理端接口扩展：1-2 天（扩展现有收银机设置保存接口）
- 收银端接口扩展：1 天（扩展 GetCashierSetting 返回新字段）
- 测试联调：1 天

### 风险识别

**潜在风险**：
1. **现有配置兼容性**：扩展现有设置可能影响现有功能
2. **JSON 字段扩展**：需要确保 JSON 解析和保存逻辑正确

**缓解措施**：
1. 新增字段使用默认值，不影响现有功能
2. 向后兼容：未配置新字段时返回默认值
3. 测试现有收银机设置接口不受影响

**说明**：
- 设备尺寸信息（商米 1024*600px，COMPAX 1280*800px）仅作为前端页面提示，用于指导用户上传合适尺寸的文件
- 后端接口统一处理文件上传，不做设备类型区分和适配
- 轮播内容最多15个，保存时进行数量验证

   - ✅ 返回点餐时展示模式（轮播内容、点餐内容、点餐内容+轮播内容）
   - ✅ 返回点餐时轮播间隔设置
   - ✅ 返回轮播内容列表（含文件URL、排序信息，最多15个）
   - ✅ 前端根据配置和当前点餐状态自行处理显示逻辑（后端不做判断）

## 📝 附录

### User Story（初稿）

**作为** 商户管理员  
**我想** 在管理端配置收银机副屏的显示内容和模式  
**以便于** 提升营销效果和顾客体验

**作为** 收银员  
**我想** 收银端能够根据配置自动展示副屏内容  
**以便于** 为顾客提供更好的服务体验

### AC 验收标准（初稿）

1. **WHEN** 管理员配置副屏设置 **THEN** 系统 **SHALL** 保存配置并返回成功
2. **WHEN** 收银端获取副屏配置 **THEN** 系统 **SHALL** 返回完整的配置信息（显示模式、轮播内容列表、切换间隔等）
3. **WHEN** 上传图片/视频 **THEN** 系统 **SHALL** 校验格式和大小，上传成功后返回文件URL
4. **说明**：前端根据获取的配置和当前点餐状态自行决定显示内容，后端不做点餐状态判断和内容切换处理

### 技术实现要点

1. **仅限接口开发**：本次不涉及前端页面开发
2. **接口设计**：扩展现有收银机设置接口，不创建新接口
3. **数据存储**：扩展现有 `setting` 表的 `cashier` 配置 JSON 字段，不创建新表
4. **文件管理**：使用现有文件上传服务，支持多格式
   - 设备尺寸信息（商米、COMPAX）仅作为前端页面提示，后端接口不做设备类型区分和适配
   - 文件上传接口统一处理，返回文件URL即可
   - 轮播内容最多15个，保存时进行数量验证
5. **缓存策略**：使用现有收银机设置缓存机制，新增字段自动包含
6. **职责划分**：
   - 后端：扩展收银机设置接口，返回完整配置信息（包含新增字段）
   - 前端：根据配置和当前点餐状态自行处理显示逻辑（未点餐/点餐时的内容切换）
