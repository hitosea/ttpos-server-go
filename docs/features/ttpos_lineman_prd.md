# ttpos 与 LINE MAN 集成产品需求文档 (PRD)

## 1. 引言

### 1.1 背景

随着餐饮行业数字化转型的加速，线上外卖平台已成为商家获取订单、拓展市场的重要渠道。LINE MAN 作为泰国领先的按需服务平台，在当地拥有庞大的用户基础和完善的外卖配送网络。为了满足 TTPOS 商家接入 LINE MAN 平台的需求，提升商家运营效率，并进一步扩大 TTPOS 在东南亚市场的竞争力，我们计划实现 TTPOS 后端系统与 LINE MAN 平台的深度集成。

### 1.2 目的

本文档旨在明确 TTPOS 与 LINE MAN 集成项目的产品愿景、目标、核心功能和业务价值，为开发、测试和产品团队提供统一的指导，确保项目顺利推进并达成预期效果。

### 1.3 产品愿景

通过 TTPOS 与 LINE MAN 的无缝集成，赋能 TTPOS 商家高效管理线上外卖业务，实现订单、菜单和门店状态的自动化同步，从而提升商家运营效率，优化用户体验，并最终促进 TTPOS 平台生态的繁荣发展。

### 1.4 业务价值

*   **提升商家运营效率：** 自动化菜单同步、订单推送及状态更新，减少人工操作，降低错误率。
*   **拓宽商家销售渠道：** 帮助 TTPOS 商家轻松接入 LINE MAN 平台，触达更广泛的线上用户群体。
*   **优化用户体验：** 实时订单状态更新，提高顾客满意度。
*   **增强 TTPOS 市场竞争力：** 提供与主流外卖平台的集成能力，吸引更多商家入驻。
*   **数据洞察：** 积累线上订单数据，为商家提供更全面的业务分析支持。

### 1.5 范围

本次 PRD 涵盖 TTPOS 后端系统与 LINE MAN 平台之间菜单管理、订单处理和门店状态控制的核心集成功能。未来可能会根据业务发展和用户反馈，逐步扩展其他集成功能。

## 2. 目标用户

*   **TTPOS 商家操作员：** 负责日常菜单管理、订单处理和门店营业状态控制的人员。
*   **TTPOS 平台管理员：** 负责管理商家配置、监控系统集成状态的人员。
*   **LINE MAN 平台用户：** 在 LINE MAN 平台下单的最终顾客。
*   **LINE MAN 平台管理员：** 负责 LINE MAN 平台商家接入、订单配送的人员。

## 3. 核心功能

TTPOS 与 LINE MAN 集成将实现以下核心功能：

### 3.1 菜单管理与同步

*   **菜单创建/更新/删除：** TTPOS 后台的菜单变更（包括商品信息、价格、库存状态、分类等）将实时或定时同步到 LINE MAN 平台。
*   **菜单项售罄/恢复：** TTPOS 可控制单个菜单项在 LINE MAN 平台上的售罄和恢复状态。
*   **LINE MAN 触发同步：** LINE MAN 平台可触发 TTPOS 进行菜单全量同步，以确保数据一致性。

### 3.2 订单处理

*   **新订单推送：** LINE MAN 平台用户下单后，新订单将实时推送至 TTPOS 后端系统。
*   **订单状态更新：** TTPOS 处理订单（如接单、备餐、完成、取消）后，将订单状态实时同步回 LINE MAN 平台。
*   **订单编辑更新 (可选)：** TTPOS 商家可对 LINE MAN 推送的订单进行修改（如增减商品、修改数量），并将修改结果同步回 LINE MAN 平台。
*   **订单编辑更新 (可选)：**  LINE MAN 用户可对订单进行修改（如增减商品、修改数量），并将修改结果同步回 TTPOS 平台。
*   **订单取消：** LINE MAN 平台可取消 LINE MAN 订单，并将取消状态同步回 TTPOS 平台。

### 3.3 门店状态控制

*   **门店营业状态控制：** TTPOS 商家可控制门店在 LINE MAN 平台上的营业（开店/关店）状态。=

### 3.4 商家外部唯一标识 (External Company ID)

*   为了安全和系统透明性，TTPOS 将为每个商家提供一个唯一的外部标识，用于与 LINE MAN 平台进行交互。该标识将确保 LINE MAN 平台能够准确识别和操作目标商家，同时避免暴露 TTPOS 内部系统结构。
*   LINE MAN 平台将使用此外部标识进行所有对 TTPOS 商家的操作和通知。

## 4. 业务流程 (高层级)

### 4.1 菜单同步流程

1.  **TTPOS 菜单变更：** 商家操作员在 TTPOS 后台修改菜单信息。
2.  **TTPOS -> LINE MAN 同步：** TTPOS 系统检测到菜单变更，将更新后的菜单数据（包含 `external_company_id`）发送到 LINE MAN 菜单同步 API。
3.  **LINE MAN 处理：** LINE MAN 平台接收并处理菜单数据。
4.  **LINE MAN -> TTPOS 通知 (可选)：** LINE MAN 将菜单同步结果通知 TTPOS。

### 4.2 订单处理流程

1.  **LINE MAN 用户下单：** 顾客在 LINE MAN 平台完成下单。
2.  **LINE MAN -> TTPOS 订单推送：** LINE MAN 平台将新订单数据（包含 `external_company_id`）推送到 TTPOS 订单接收 API。
3.  **TTPOS 订单处理：** TTPOS 系统接收订单，将其转换为内部订单，进行库存扣减、厨房打印等操作。
4.  **TTPOS -> LINE MAN 状态更新：** TTPOS 将订单状态变更（如接单、完成）发送到 LINE MAN 订单状态更新 API。
5.  **LINE MAN 用户查看：** LINE MAN 用户可在平台查看实时订单状态。

### 4.3 门店状态控制流程

1.  **TTPOS 控制门店状态：** 商家操作员在 TTPOS 后台调整门店营业状态。
2.  **TTPOS -> LINE MAN 控制：** TTPOS 将门店状态变更请求（包含 `external_company_id`）发送到 LINE MAN 门店状态控制 API。
3.  **LINE MAN 更新：** LINE MAN 平台更新门店营业状态。

## 5. 产品成功指标

*   **订单集成成功率：** 99.9% 以上的 LINE MAN 订单能成功推送到 TTPOS 并被识别处理。
*   **菜单同步成功率：** 99% 以上的菜单更新能成功同步到 LINE MAN 平台。
*   **订单状态同步实时性：** 订单状态变更在 5 秒内同步到 LINE MAN 平台。
*   **商家满意度：** 接入 LINE MAN 的 TTPOS 商家对集成功能和稳定性表示满意（通过问卷调查或反馈收集）。
*   **错误率：** LINE MAN 相关 API 调用错误率低于 0.1%。

## 7. 市场分析 (简要)

TTPOS 与 LINE MAN 的集成将显著提升 TTPOS 在泰国及东南亚市场的竞争力。它将使 TTPOS 能够服务于更广泛的商家群体，特别是那些依赖 LINE MAN 平台进行线上销售的商家。此举有望增加 TTPOS 的市场份额，并增强其作为综合性餐饮解决方案提供商的吸引力。
