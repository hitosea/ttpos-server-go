# H5Order 实体模型说明

## 基本信息

- **实体名称**: H5Order
- **表名**: ttpos_h5_order
- **所属模块**: model
- **描述**: H5扫码点餐订单实体，用于管理顾客通过扫码方式下单的订单，包含订单状态管理、接单拒单处理等完整生命周期

## 数据流分析

### 数据来源
- H5移动端扫码下单
- 微信小程序下单
- 支付宝小程序下单
- 其他移动端扫码点餐

### 数据流向
1. **下单流程**:
   - 顾客扫码进入H5点餐页面
   - 选择商品并加入购物车
   - 提交订单，创建H5Order记录，状态为未下单(0)
   - 确认下单后状态变为未接单(1)

2. **接单流程**:
   - 商家在收银台查看H5订单列表
   - 商家确认接单，状态变为已接单(2)
   - 自动创建订单商品快照信息
   - 计算订单总价和金额

3. **拒单流程**:
   - 商家查看订单详情后选择拒单
   - 状态变为已拒单(3)
   - 记录拒单员工和时间
   - 推送拒单通知到客户端

4. **自动接单流程**:
   - 根据商家设置自动接单规则
   - 当满足条件时自动接单
   - 设置 IsAutoAccept 标志为1

### 业务场景
- H5扫码点餐订单管理
- 移动端下单流程
- 商家接单拒单处理
- 订单状态实时推送
- 自动接单规则配置
- 订单审核流程
- 移动端与收银台数据同步

## 业务方法

### Reject(staffUuid uint64, lang string)
- **功能**: 拒单处理
- **参数**: 员工UUID、语言类型
- **用途**: 商家拒单操作，更新订单状态和快照信息

### Accept(staffUuid uint64, lang string)
- **功能**: 接单处理
- **参数**: 员工UUID、语言类型
- **用途**: 商家接单操作，更新订单状态和快照信息

### Handle(staffUuid uint64, lang string, status uint)
- **功能**: 处理订单状态变更
- **参数**: 员工UUID、语言类型、目标状态
- **用途**: 统一的订单状态处理逻辑

### CalcProductTotalPrice() float64
- **功能**: 计算商品总价
- **返回**: 商品总价
- **用途**: 根据订单商品计算总金额

### GetSubProducts(saleOrderProductUuid uint64) []*SaleOrderProduct
- **功能**: 获取套餐子商品列表
- **参数**: 套餐商品UUID
- **返回**: 子商品列表
- **用途**: 处理套餐商品的子商品管理

### DeleteSaleOrderProduct()
- **功能**: 删除销售订单商品
- **用途**: 订单取消时删除相关商品记录

### ChangeToAccepted()
- **功能**: 将已下单的H5订单商品变为已接单
- **用途**: 状态变更时同步商品状态

## 注意事项

1. **状态管理**: 严格的状态流转控制，确保订单状态的一致性
2. **快照机制**: 接单和拒单后创建商品快照，价格和属性信息不再改变
3. **多语言支持**: 商品名称和属性支持多语言显示
4. **自动接单**: 支持配置自动接单规则和条件
5. **审核机制**: 支持H5订单审核流程，可配置是否需要审核
6. **软删除**: 使用DeleteTime实现软删除机制
7. **关联一致性**: 确保与销售订单和销售账单的一致性
8. **实时推送**: 状态变更时需要推送到相关客户端

## 业务规则

1. **状态流转**: 未下单(0) → 未接单(1) → 已接单(2)/已拒单(3)
2. **接单条件**: 只有状态为未接单(1)的订单可以接单或拒单
3. **快照时机**: 接单和拒单时创建商品快照信息
4. **自动接单**: 根据商家设置和订单金额自动接单
5. **审核规则**: IsNeedAudit=1时需要手动审核，否则自动处理
6. **员工权限**: 接单和拒单需要记录操作员工信息
7. **时间限制**: 订单创建和接单拒单需要在规定时间内完成
8. **金额计算**: 订单金额基于商品快照信息计算
