# PrinterLog 实体模型说明

## 基本信息

- **实体名称**: PrinterLog
- **表名**: printer_log
- **所属模块**: model
- **描述**: 打印日志实体，用于记录和管理打印任务的历史记录

## 数据流分析

### 数据来源
- POS收银系统发起的打印任务
- 厨房系统自动打印的订单
- API接口触发的打印请求
- 定时任务生成的报表打印

### 数据流向
1. **打印任务创建流程**:
   - 系统创建打印任务
   - 设置打印内容和参数
   - 压缩打印内容（如果需要）
   - 记录打印任务状态为pending

2. **打印执行流程**:
   - 打印服务获取待打印任务
   - 更新状态为printing
   - 发送打印内容到打印机
   - 处理打印机响应

3. **打印结果处理流程**:
   - 打印成功时更新状态为success
   - 打印失败时记录错误信息
   - 失败时根据策略决定是否重试
   - 更新完成时间和重试次数

4. **打印重试流程**:
   - 检查重试次数限制
   - 重新发送打印任务
   - 更新重试计数
   - 最终失败时记录详细错误

### 业务场景
- 餐厅订单打印（厨房小票、收银小票）
- 零售商品标签打印
- 财务报表打印
- 库存报表打印

## WebSocket推送

### AfterCreate钩子
- **打印任务推送**: 当创建打印任务时，推送到指定设备
- **推送内容**: 打印内容、打印机信息、优先级

### 推送目标
- **厨房打印机**: 厨房订单打印任务
- **收银打印机**: 收银小票打印任务
- **标签打印机**: 商品标签打印任务
- **管理端**: 打印状态更新、错误通知

## 业务方法

### CanRetry() bool
- **功能**: 判断是否可以重试
- **返回**: 是否可重试
- **用途**: 重试策略判断

### GetElapsedTime() int64
- **功能**: 获取打印耗时
- **返回**: 耗时（毫秒）
- **用途**: 性能分析

### IsExpired(timeout int64) bool
- **功能**: 判断打印任务是否超时
- **参数**: 超时时间（毫秒）
- **返回**: 是否超时
- **用途**: 超时任务处理

### GetDecompressedContent() string
- **功能**: 获取解压缩后的内容
- **返回**: 解压缩内容
- **用途**: 内容还原

### SetCompressedContent(content string) error
- **功能**: 设置压缩内容
- **参数**: 原始内容
- **返回**: 错误信息
- **用途**: 内容压缩存储

## 注意事项

1. **多租户支持**: 通过CompanyUuid实现数据隔离
2. **内容压缩**: 大内容需要压缩存储以节省空间
3. **重试机制**: 需要合理的重试策略和次数限制
4. **错误处理**: 详细记录打印错误信息用于排查
5. **状态管理**: 严格的状态流转控制
6. **实时推送**: 通过WebSocket确保打印任务及时送达
7. **数据清理**: 定期清理过期的打印日志

## 业务规则

1. **重试限制**: 重试次数不能超过系统设定的最大值
2. **优先级处理**: 高优先级任务需要优先处理
3. **打印份数**: 打印份数必须为正数
4. **超时处理**: 超时的任务需要标记为失败
5. **设备状态**: 只有在线的打印机才能接收打印任务
6. **内容验证**: 打印内容不能为空
7. **权限控制**: 只有有权限的用户才能发起打印
