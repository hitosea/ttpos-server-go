## 四、核心计算公式详解

### 4.1 销售统计核心公式

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                            销售统计核心计算公式                                   │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ★★★ 1. 总销售额 (TotalSaleAmount) ★★★                                          │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalSaleAmount = Σ(                                                   │    │
│  │      product_price     // 商品价格(含折扣后)                              │    │
│  │    + product_tax       // 商品税                                         │    │
│  │    + service_fee       // 服务费                                         │    │
│  │    + service_tax       // 服务费税                                       │    │
│  │    + payment_fee       // 支付手续费                                     │    │
│  │    + extend_price      // 扩展价格(加钟等)                                │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: SUM(product_price + product_tax + service_fee + service_tax       │    │
│  │           + payment_fee + extend_price)                                 │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 2. 总实收金额 (TotalReceivedAmount) ★★★                                    │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalReceivedAmount = Σ(                                               │    │
│  │      payment_amount      // 支付金额                                     │    │
│  │    - refund_amount       // 退款金额                                     │    │
│  │    - payment_balance     // 余额支付(不计入实收)                          │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: SUM(payment_amount - refund_amount - payment_balance)             │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 3. 总营业收入 (TotalBusinessAmount) ★★★ [重点]                              │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalBusinessAmount = Σ(                                               │    │
│  │      payment_amount          // 支付金额                                 │    │
│  │    - refund_amount           // 退款金额                                 │    │
│  │    - refund_payment_balance  // 退款余额                                 │    │
│  │    - product_tax             // 商品税(需上交)                           │    │
│  │    - service_tax             // 服务税(需上交)                           │    │
│  │    + refund_tax              // 退款时返还的税                           │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: SUM(payment_amount - refund_amount - refund_payment_balance       │    │
│  │           - product_tax - service_tax + refund_tax)                     │    │
│  │                                                                         │    │
│  │  ★ 解释: 营业收入 = 实收 - 代收税费                                       │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 4. 总税费 (TotalTax) ★★★                                                   │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalTax = Σ(                                                          │    │
│  │      product_tax     // 商品税                                           │    │
│  │    + service_tax     // 服务税                                           │    │
│  │    - refund_tax      // 退款返还税(需扣除)                                │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: SUM(product_tax + service_tax - refund_tax)                       │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 5. 总退款金额 (TotalRefundAmount) ★★★                                      │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalRefundAmount = Σ(                                                 │    │
│  │      refund_amount           // 现金退款                                 │    │
│  │    + refund_payment_balance  // 余额退款                                 │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: SUM(refund_amount + refund_payment_balance)                       │    │
│  │                                                                         │    │
│  │  ★ 细分:                                                                 │    │
│  │    - 整单退款 (FullRefund): refund_type = 1                             │    │
│  │    - 部分退款 (PartialRefund): refund_type = 2                          │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 6. 总优惠折扣 (TotalDiscount) ★★★                                          │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalDiscount = Σ(                                                     │    │
│  │      discount           // 订单折扣                                      │    │
│  │    - refund_discount    // 退款返还折扣(需扣除)                           │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: SUM(discount - refund_discount)                                   │    │
│  │                                                                         │    │
│  │  ★ 折扣率:                                                               │    │
│  │  DiscountRatio = (TotalDiscount / TotalSaleAmount) × 100%               │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 订单统计公式

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                            订单统计计算公式                                       │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ★★★ 1. 订单数量 (TotalOrderNum) ★★★                                            │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalOrderNum = COUNT(                                                 │    │
│  │      CASE WHEN is_meger = 0 THEN 1 END   // 排除并单订单                 │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  SQL: COUNT(CASE WHEN is_meger = 0 THEN 1 END)                          │    │
│  │                                                                         │    │
│  │  ★ is_meger 说明:                                                        │    │
│  │    - 0: 独立订单                                                         │    │
│  │    - 1: 被并入其他订单的子订单(不重复计数)                                 │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 2. 平均订单金额 (AvgOrderAmount) ★★★                                       │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  AvgOrderAmount = Σ(avg_order_amount) / COUNT(独立订单)                  │    │
│  │                                                                         │    │
│  │  SQL: ROUND(                                                            │    │
│  │           SUM(avg_order_amount) / SUM(IF(is_meger = 0, 1, 0)),          │    │
│  │           2                                                             │    │
│  │       )                                                                 │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 3. 最小/最大订单金额 ★★★                                                    │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │

│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  MaxOrderAmount = MAX(                                                  │    │
│  │      CASE WHEN order_amount > 0                                         │    │
│  │            AND is_meger = 0                                             │    │
│  │      THEN order_amount ELSE NULL END                                    │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │
│                                                                                 │
│  ★★★ 4. 消费桌数 (TotalDeskNum) ★★★                                             │
│  ┌─────────────────────────────────────────────────────────────────────────┐    │
│  │                                                                         │    │
│  │  TotalDeskNum = COUNT(                                                  │    │
│  │      CASE WHEN desk_uuid > 0 AND is_meger = 0 THEN 1 END                │    │
│  │  )                                                                      │    │
│  │                                                                         │    │
│  │  ★ desk_uuid > 0 表示桌台订单                                            │    │
```

## 九、综合运营统计 (BusinessSummary) 公式汇总

```
│  │                                                                         │    │
│  └─────────────────────────────────────────────────────────────────────────┘    │

│  │                                                                         │    │

│  │                         优惠折扣                                         │    │
│  │                                                                         │    │

│  │  会员折扣 = Σ(discount_member)                                          │    │
```

## 十三、重点逻辑标注

### 关键点 1: is_meger 字段
- **作用**: 标识订单是否被并入其他订单
- **重要性**: 统计订单数时必须排除 `is_meger=1` 的记录，避免重复计算
- **影响范围**: OrderNum, AvgOrderAmount, MinOrderAmount, MaxOrderAmount

### 关键点 2: 外卖数据合并
- **来源**: BMP微服务的 takeout 模块
- **方式**: 通过 gRPC 调用获取，在 Service 层合并
- **公式**: 所有指标需要累加店内和外卖两部分

### 关键点 3: 营业收入 vs 销售额
- **销售额**: 客户实际支付的全部金额（含税费）
- **营业收入**: 扣除代收税费后的净收入
- **计算差异**: 营业收入 = 销售额 - 税费

### 关键点 4: 时间维度处理
- **优先级**: TimeType > StartTime/EndTime > StartDate/EndDate
- **时区**: 需考虑商户所在时区
- **营业时间**: 支持跨午夜的营业时间配置

### 关键点 5: 事件驱动更新
- **触发时机**: 订单结账/会员充值时发布事件
- **处理方式**: 异步处理，先删后插
- **幂等性**: 支持重复执行（先删除再保存）
