## 八、关键决策记录

### 决策1：BMP-ERP保持现状 ✓
```
理由：
• TTPOS定位为"餐饮+ERP一体化"
• ERPNext提供专业进销存能力
• 架构合理，无需改动
```

### 决策2：独立数据库方案保持 ✓
```
理由：
• 便于数据迁移（库对库copy）
• 通过连接池优化控制连接数
• 不影响数据隔离和安全
```

### 决策3：离线能力暂缓（P2）✓
```
理由：
• 客户暂无痛点
• 优先解决开发效率和扩展性
• 待竞争需要时再做
```
