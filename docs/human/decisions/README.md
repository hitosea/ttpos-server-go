# 技术决策记录 (ADR)

> Architecture Decision Records

---

## 📋 说明

本目录存放技术决策记录（ADR），记录重要的架构和技术选择。

---

## 📝 ADR 命名规范

### 格式
```
{YYYY-MM-DD}-{决策标题}.md
```

### 示例
```
2025-11-16-choose-gin-framework.md
2025-11-16-database-migration-strategy.md
2025-11-16-microservice-architecture.md
```

---

## 🎯 ADR 应该包含

1. **背景** - 为什么需要做这个决策？
2. **决策** - 我们决定采用什么方案？
3. **理由** - 为什么选择这个方案？
4. **权衡** - 考虑了哪些替代方案？
5. **后果** - 这个决策会带来什么影响？
