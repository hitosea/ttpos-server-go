# /dootask - 读取任务详情

## 使用场景

快速查看 DooTask 任务的完整信息，包括任务描述、负责人、协助人员、时间安排等。

## 使用方式

```bash
/dootask 36917                    # 读取任务 ID 为 36917 的详情
/dootask 22222                    # 读取任务 ID 为 22222 的详情
```

## 参数

- `task_id`: 必填，DooTask 任务编号（纯数字）

## 功能特点

- ✅ 调用 DooTask MCP 服务读取任务详情
- ✅ 格式化展示任务完整信息
- ✅ 显示任务描述、内容、负责人、协助人员
- ✅ 显示任务时间安排（开始时间、结束时间、完成时间）
- ✅ 显示任务状态和优先级
- ✅ 显示所属项目和看板列信息
- ✅ 错误处理：任务不存在时给出明确提示

## 执行流程

1. **参数验证**
   - 检查 task_id 是否为数字
   - 验证参数格式是否正确

2. **调用 MCP 服务**
   - 使用 `mcp_DooTask_get_task` 工具
   - 传入 task_id 参数

3. **错误处理**
   - 捕获"任务不存在"错误
   - 捕获权限错误
   - 捕获网络错误

4. **格式化输出**
   - 解析任务数据
   - 按结构化格式展示
   - 高亮关键信息

## 使用示例

### 示例 1: 查看功能开发任务

```bash
/dootask 36917
```

**场景**: 查看正在开发的功能任务详情，了解需求和进度。

### 示例 2: 查看 Bug 修复任务

```bash
/dootask 38520
```

**场景**: 查看 Bug 修复任务，了解问题描述和解决方案。

### 示例 3: 配合 /spec-propose 使用

```bash
# 先查看任务详情
/dootask 36917

# 然后基于任务创建提案
/spec-propose quick-payment 编号:36917
```

**场景**: 先详细了解任务内容，再创建需求提案。

## 相关指令

- `/spec-propose` - 基于任务创建需求提案
- `/spec-create` - 创建功能规格文档

## 技术实现

使用 DooTask MCP 服务的以下工具：
- `mcp_DooTask_get_task(task_id)` - 获取任务详情
- 返回包含任务完整信息的 JSON 对象
