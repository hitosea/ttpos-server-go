**响应格式**
```
{
    "code": 1,
    "data": [],
    "msg": "操作成功！"
}
```
<br>
<br>

**状态码说明**

| 状态码（code）   | 含义说明（msg）                                        |
| -------------- | ----------------------------------------------------- |
| 1              | 调用成功                                               |
| 0              | 调用失败，系统异常或其他原因                              |
| -1              | 当前登录用户被删除或者其他，需要回到登录页                              |
| -2              | token过期或者token错误，需要回到登录页                              |
| -3              | 桌台已关闭，请重新开台，返回桌台页                              |
| -4              | 访问失效                              |
| -5              | 桌台用餐已关闭, 对应业务被关闭，需要自行处理                              |
| -6              | 桌台已结账                              |
| -20              | 未开启功能                              |
| -21              | 设备上限                              |
| -102              | 店铺到期                              |
| -201              | 设备已解绑，请重新绑定                              |
